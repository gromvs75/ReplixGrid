# Development

## Setup and commands

The project was last checked with Node 20.19.6 and npm 10.8.2. Install dependencies from the lockfile with `npm ci`.

- `npm run dev` builds the geometry worker and starts Vite at `127.0.0.1:5173` with a fixed port.
- `npm run typecheck` checks TypeScript; `npm test` runs the Node test suite.
- `npm run build` typechecks, rebuilds the worker and WebAssembly assets, and builds static output in `dist/`.
- `npm run preview` serves an existing build locally; `npm run samples` creates engineering samples.

The build needs `manifold-3d` from the installed dependencies. `public/kernel/` is generated by `build:kernel` and is deliberately excluded from version control; do not delete it while a running app needs it. The Vite build has previously reported a large JavaScript chunk.

## Structure

`src/ui/` contains React UI and the Three.js preview; `src/model.ts`, `editor.ts` and `store.ts` define project state and editing. Geometry, validation, splitting and export logic live in `src/`; `src/worker.ts` runs the geometry kernel off the UI thread. IndexedDB stores local projects, while portable project JSON and printable files are separate exports. `tests/` contains automated checks. `public/guides/` contains guide assets; `src/fonts/NOTICE` retains the third-party font license.

Localization catalogs are in `src/locales/`. Translation scripts in `scripts/` are development utilities, not runtime dependencies. `scripts/translate-catalogs.py` contacts an external translation service if run. Translations require human review.

## Verification and release

Run the test suite and production build, then exercise project save/import and representative exports in a browser. Inspect exported objects and print preparation in a slicer; automated mesh checks are not physical validation. Record exact versions and results. Consult the user guide for current behavior and limitations.
