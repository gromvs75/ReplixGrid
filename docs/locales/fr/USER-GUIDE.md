# Votre premier organiseur ReplixGrid

<a id="first-visit-and-a-clean-start"></a>
## Premier lancement et nouveau projet

Au premier lancement, la zone de travail est vide. Le guide à gauche propose trois étapes: **Choisir une forme → Définir les dimensions → Ajouter des compartiments**. Choisissez une forme, réglez ses dimensions, puis cliquez sur **Suivant : compartiments**. Terminez avec **Terminé** ou **Garder sans cloisons**. Après avoir choisi une forme, vous pouvez fermer le guide avec **×**. Vous pouvez aussi ouvrir un projet enregistré ou un fichier JSON.

**Sur les petits écrans :** lorsque la fenêtre du navigateur mesure 1400 px de large ou moins, l’assistant se place **sous le modèle** pour ne pas masquer l’aperçu. Faites défiler la **page vers le bas** pour accéder à l’assistant, aux étapes suivantes et aux boutons permettant de passer aux compartiments et de terminer. Remontez la page pour revoir le modèle. Dans une fenêtre plus large, l’assistant reste à côté du menu de gauche.

Rouvrez le guide via **Aide → Guide : trois étapes**. Son ouverture ne modifie pas le modèle. Choisir une autre forme remplace le modèle actuel; cette action peut être annulée.

Le démarrage rapide, le guide utilisateur et le menu d’aide utilisent la langue de l’interface. La vidéo reste en anglais.

Les étapes, conseils et confirmations du guide sont traduits. La ligne du modèle enregistré porte le nom **Projet précédent**. Les noms réels dans **Mes projets** restent tels que vous les avez enregistrés.

Cliquez sur **Nouveau projet** dans la barre supérieure pour repartir d’une zone vide. Le travail précédent, même sans nom, est conservé dans **Mes projets**. La ligne **Projet précédent**, avec sa miniature, ouvre la bibliothèque. La zone reste vide jusqu’au choix d’une forme. Le nouveau modèle ne comporte ni cloisons ni accessoires; la forme en nid d’abeilles conserve ses cellules reliées. Ouvrir un projet enregistré restaure son modèle. Choisir un modèle dans **Forme → Socle** modifie le projet actuel; **Nouveau projet** en crée un autre.


[Ouvrir ReplixGrid](https://grid.replixcast.com/?lang=fr) · [Guide utilisateur](REFERENCE.md)

Commencez par un organiseur à trois compartiments pour votre bureau. L'exemple ci-dessous est 180 × 90 mm, avec un front bas pour un accès facile et un dos plus grand. Tout ce que vous devez concevoir est un navigateur. Pour préparer le fichier pour votre imprimante, ouvrez-le dans votre slicer habituel.

[Voir la vidéo de démarrage rapide en anglais (1:03)](https://grid.replixcast.com/guides/quick-start-en.mp4) pour voir comment diviser un compartiment, parer les bords supérieurs, ajouter un couvercle à deux tons et exporter un 3MF.

<a id="find-your-controls"></a>
## Repérer les commandes

- **En haut à gauche:** choisissez **Forme**, **Compartiments**, **Habillage** ou **Impression**. Le menu de gauche liste les sections de cet outil.
- **Au bas de l'aperçu:** la sélection d'une section ouvre un éditeur de paramètres compacts et flottants. La scène et la grille continuent derrière elle. Seule la section sélectionnée apparaît ici. Utilisez le chevron pour l'effondrer ou **×** pour la fermer; choisissez une autre section à gauche pour continuer.
- **Au-dessus du modèle :** choisissez **Assemblage**, **Organiseur**, **Inserts**, **Habillage** ou **Couvercle**. Le menu à côté de **Organiseur** permet de choisir un étage ou **Afficher la pile** pour la pile complète, sans fermer l’éditeur inférieur. Seules les pièces présentes sont disponibles. Dans une fenêtre étroite, les boutons passent sur une ligne séparée.
- **Sur la droite:** cliquez sur un numéro de compartiment, un mur ou un cloison pour modifier cet élément.

Dans **Forme**, commencer par **Socle**, puis utiliser **Dimensions**. Dans **Habillage**, choisir le motif, le type de habillage, la couleur, l'épaisseur/rim et s'adapter dans leurs sections distinctes. Dans **Impression**, choisir une imprimante, configurer les emplacements de filament, ou ouvrir les commandes d'impression de section.

Pendant que vous déplacez un curseur, le modèle se met à jour à la fin de chaque calcul. Les modèles complexes peuvent prendre plus de temps; la valeur finale est toujours calculée à pleine précision. Attendez l'aperçu terminé avant de vérifier ou d'exporter le résultat. Les notifications de l'éditeur disparaissent après 10 secondes, ou vous pouvez les fermer avec **×**.

La vidéo de démarrage rapide a été enregistrée avec la mise en page du panneau précédent. Les étapes de modélisation s'appliquent toujours; utilisez les emplacements ci-dessus pour trouver les contrôles actuels.

<a id="build-the-example"></a>
## Réaliser l’exemple

1. **Ouvrir** [grid.replixcast.com](https://grid.replixcast.com/?lang=fr). Utilisez le menu langue dans la barre supérieure pour changer les langues. Si vous avez déjà un design que vous voulez conserver, cliquez sur **Enregistrer le projet** pour télécharger une copie modifiable avant de commencer.
2. **Créez le corps.** Ouvrir **Forme**, choisir **Capsule** sous **Socle** et **En pente** sous **Profil en hauteur**, puis cliquer **Créer à partir d'un modèle**. L'aperçu doit montrer deux cloisons et trois compartiments numérotés. La bord passe de 22 à 70 mm. Créer un modèle remplace le design actuel; la flèche incurvée défaire le restaure.
3. **Mets-le dans ton espace.** Sous **Forme → Dimensions**, entrez la largeur extérieure et la profondeur en millimètres. Cliquez sur un compartiment numéroté pour lire ses dimensions intérieures. Sous **Dimensions intérieures**, entrez la largeur ou la profondeur requise, ou cliquez sur l'étiquette de la dimension bleue sur le modèle et tapez la valeur. Cliquez sur l'extérieur pour appliquer. Commencez par le compartiment 1 et travaillez dans l'ordre dans une rangée simple; le dernier compartiment reçoit le reste. Les extrémités arrondies peuvent se rétrécir de la ligne de mesure, ainsi vérifier l'empreinte de l'objet et laisser la jeu.
4. **Réglez la disposition si nécessaire.** Passez à **Dessus**, sélectionnez un compartiment, ensemble **Nombre de pièces** à **2**, puis cliquez **Diviser en largeur** ou **Diviser en profondeur**. Seul le compartiment sélectionné se divise. Cliquez sur un cloison pour ajuster sa position, ou sélectionnez un élément de **Toutes les parois et compartiments** dans le panneau droit. Déplacer un cloison sélectionné change les compartiments de chaque côté tout en maintenant d'autres positions de cloison fixes. Retourner à **3D** pour inspecter le résultat.

5. **Terminer les bords supérieurs (facultatif).** Sous **Forme → Coins et chanfreins**, trouver **Bord supérieur des parois et des cloisons**. Choisir **Chanfrein** pour un biseau plat ou **Arrondi** pour un bord courbé. Entrez la taille en millimètres; le maximum dépend de l'épaisseur du mur de sorte qu'une bande plate reste sur le dessus. La finition suit les deux côtés des murs extérieurs et des cloisons. Choisir **Aucune** pour restaurer les bords carrés.

<a id="try-a-two-tone-lid-optional"></a>
## Essayer un couvercle bicolore

Un couvercle nécessite un bord supérieur de hauteur uniforme. Pour conserver la capsule inclinée de l’exemple, téléchargez d’abord une sauvegarde avec **Enregistrer le projet**. Dans **Forme**, choisissez ensuite **Capsule** et le profil de hauteur **Lisse**, puis **Créer à partir d'un modèle**.

1. Ouvrir **Forme → Couvercle** et ajouter un couvercle. Sous **Ajustement du couvercle**, choisissez **Coiffant** pour un couvercle qui recouvre la bord ou **Encastré** pour un couvercle qui est assis à l'intérieur. Le couvercle à deux tons a besoin de murs d'au moins 2 mm d'épaisseur et d'une profondeur intérieure d'au moins 5,2 mm.
2. Activez **Motif bicolore** et choisissez un **Lid pattern**. Pour essayer les feuilles en forme de ventilateur dans la galerie, sélectionnez **Feuilles de ginkgo**.
3. Jeu **Couleur de base du couvercle** à la couleur d'arrière-plan et **Couleur du motif du couvercle** à la couleur du dessin. Pour la combinaison ci-dessous, choisissez la crème pour la base et le vert olive pour le motif.

Choisissez les couleurs de la base, du motif et de la poignée dans **Filaments du slicer**, depuis leur fenêtre de couleur. Configurez d’abord les emplacements dans **Impression → Filaments du slicer**. **Comme la base du couvercle** lie la poignée à la base ; choisir une autre couleur la rend indépendante. Exportez en 3MF et vérifiez les affectations des filaments.

![Couvercles bicolores, de gauche à droite. La rangée supérieure montre la branche d'olive, les feuilles de Ginkgo et la fronde de Fern. La rangée inférieure montre les vagues de marée, les cailloux de rivière et les anneaux de croissance.](../../images/lid-motifs.svg)

**Motif bicolore** est disponible pour les deux types de couvercles. Choisissez branche d’olivier, feuilles de ginkgo, fougère, vagues, galets, cernes du bois ou cellules de Voronoï, puis les couleurs du fond et du motif. La plaque de 3,2 mm comprend un fond plein de 1,6 mm et une couche à motif de 1,6 mm. Le rebord extérieur et la poignée augmentent la hauteur totale. Un couvercle encastré exige au moins 5,2 mm de profondeur intérieure. Exportez en 3MF pour conserver les deux pièces colorées ensemble et affectez leurs filaments. Pour l’olivier, le ginkgo, la fougère, les vagues et les cernes, **Motif ajouré** crée des ouvertures dans la couche supérieure. **Motif en relief** laisse ces ouvertures de 1,6 mm vides et révèle le fond ; désactivez-le pour une incrustation lisse. Les couvercles encastrés en relief s’impriment fond vers le bas, les couvercles extérieurs motif vers le bas. Vérifiez les ponts au-dessus des creux dans le slicer.

<a id="download-your-first-print"></a>
## Télécharger votre premier modèle

1. Ouvrez **Impression** et choisissez la configuration de votre imprimante ou entrez son volume d’impression.
2. Cliquez sur **↓ Télécharger** dans la barre supérieure. Dans **Vérification et téléchargement**, choisissez **Organisateur et accessoires**. Si vous avez ajouté un shell et que vous le voulez aussi, choisissez l'ensemble du kit.
3. Choisissez **STL** pour un corps monocolore, ou **3MF** pour garder des parties, des couleurs et des attributions de filaments séparés. Attendez les vérifications de la géométrie et de la taille. Si une partie ne correspond pas, corrigez les dimensions ou construisez le volume et rouvrez la boîte de dialogue.
4. Cliquez sur **↓ Télécharger STL** ou **↓ Télécharger 3MF** en bas de la boîte de dialogue. Si plusieurs fichiers STL arrivent dans un ZIP, les extraire d'abord.
5. Ouvrez le modèle dans votre slicer et vérifiez les dimensions en millimètres. Posez le fond de l’organiseur sur le plateau et disposez les autres pièces. Choisissez les profils d’imprimante et de matériau, lancez le découpage, puis vérifiez la première couche et les cloisons dans l’aperçu des couches avant d’imprimer.

<a id="projects-and-backups"></a>
## Projets et sauvegardes

Ouvrez **Mes projets** et enregistrez une copie nommée. Le projet ouvert enregistre automatiquement. Vous pouvez également y rechercher, renommer, ouvrir, supprimer ou télécharger des projets. Le travail sans nom est conservé en tant qu'ébauche. Téléchargez un fichier JSON de projet en tant que sauvegarde ou pour le transférer, puis cliquez sur **Ouvrir** dans la barre supérieure pour le charger. Un fichier endommagé doit signaler une erreur de validation sans remplacer le projet en cours.

Les modifications appliquées sont enregistrées immédiatement. Si une écriture est interrompue, la réouverture de l'application restaure sa copie de récupération temporaire. Si la session actuelle est endommagée, l'application essaie son dernier instantané réussi. Quand aucune copie ne peut être restaurée, l'enregistrement automatique s'arrête pour protéger les données stockées; utilisez **Ouvrir** pour restaurer une sauvegarde JSON téléchargée. Si l'enregistrement signale une erreur, téléchargez une sauvegarde de projet avant de partir.

Les contrôles d'exportation utilisent les dernières modifications appliquées et les pièces sélectionnées. Après avoir modifié les dimensions ou la position de montage, attendez une nouvelle vérification avant de télécharger.

Lorsque le même projet ou tiroir est édité dans plusieurs onglets, des modifications contradictoires sont enregistrées séparément **Copy from another tab**. L'autre version est conservée, et l'onglet d'édition continue avec sa copie. Comparez les versions dans **Mes projets** ou le sélecteur de tiroir et renommez la copie si vous voulez la conserver. Réouverture d'un onglet organiseur restaure son propre projet sauvegardé. Les modifications ne sont pas automatiquement fusionnées entre les onglets.

La bibliothèque est stockée dans votre navigateur et liée à l'adresse du site. Effacer les données du site ou modifier les navigateurs, les appareils ou les adresses peut le rendre indisponible. Gardez une sauvegarde séparée de fichier de projet. Les emplacements de filament sont stockées séparément dans le navigateur et ne sont pas incluses dans le projet JSON; configurez-les à nouveau sur un autre appareil.

<a id="filaments-and-export-options"></a>
## Filaments et formats d’exportation

Pour un fichier 3MF multicolore, configurez les emplacements dans **Impression** avec les mêmes numéros et couleurs que dans le slicer. Sur le Snapmaker U1, les quatre premiers correspondent à T0–T3. Affectez un emplacement à chaque pièce dans la fenêtre de téléchargement, puis vérifiez les affectations dans Snapmaker Orca. Une pièce sans affectation peut utiliser le premier filament. Les profils d’imprimante et de matériau se règlent dans le slicer.

Pour un OBJ coloré, gardez le fichier OBJ et son fichier MTL dans le même dossier. Le contrôle d'exportation permet une marge de 2 mm aux bords du plateau pour chaque partie.

<a id="print-a-large-organizer-in-sections"></a>
## Imprimer un grand organiseur en plusieurs parties

Dans **Impression**, réglez le volume d’impression et choisissez deux ou trois sections, ou les découpes proposées. Les parois passent à au moins 5 mm et le fond à au moins 3 mm, ce qui modifie les dimensions des compartiments. L’application demande de retirer les habillages et les inserts avant la division. Certaines formes et certains réglages ne permettent pas cette division.

Téléchargez l'échantillon de joint, placez ses moitiés séparément et imprimez à 100%. Une fois refroidis, vérifiez l'ajustement des goupilles. Ensuite, téléchargez le kit, inspectez toutes les pièces de la trancheuse, imprimez-les et assemblez-les après refroidissement avec des goupilles et de la colle. Les dimensions nominales des goupilles sont Ø 3.2 × 8 mm; chaque trou est Ø 3.3 mm et 4.5 mm de profondeur.

<a id="shells"></a>
## Habillages

Les modèles de shell dense peuvent prendre plusieurs secondes pour recalculer. Si un shell ne parvient pas à construire, l'organiseur construit avec succès reste visible et l'erreur reste disponible; cela ne rend pas le shell prêt pour l'impression. Corriger les paramètres de shell et lancer la vérification de téléchargement à nouveau. Exporter valide toujours chaque partie demandée.

Une habillage décorative en une seule pièce est construite autour du corps de l'organiseur. Lors de l'ajout d'un motif shell à un organiseur empilé avec des garnitures de fond, l'application sélectionne automatiquement un shell en une seule pièce; la garniture reste sur le premier niveau. Pour utiliser des panneaux séparés, ouvrez **Habillage → Тип оболочки → Panneaux décoratifs**. Les panneaux préservent l'épaisseur des parois et les dimensions des compartiments. Avec des murs de 2,4 mm et un fond de 2 mm, laisser **Montures cachées** et collez les panneaux en place. Les fixations cachées nécessitent des parois d'au moins 3,2 mm d'épaisseur sans relief. Les fonds des panneaux sont situés au-dessus de la garniture; **Décalage de bord** commence au sommet de la garniture et doit être d'au moins 3 mm sur les plateaux empilés. On ne peut pas combiner les raccords à ressort et les planchers plus minces que 1,2 mm avec les garnitures de fond supportant la habillage. Inspectez la sortie de l'aperçu et de la trancheuse, et vérifiez l'ajustement avec une petite impression avant d'imprimer un ensemble complet.


<a id="match-another-organizer"></a>
## Reprendre le style d’un autre organiseur

Utilisation **Forme → Style commun** pour enregistrer les couleurs et les motifs actuels avec un nom. Ouvrez un autre projet, choisissez ce style sauvegardé, et cliquez sur **Appliquer le style**. Vous pouvez transférer des couleurs, des motifs ou les deux tout en gardant les dimensions et les compartiments de la destination. Voir [Styles partagés](REFERENCE.md#shared-styles) pour les détails de compatibilité et de stockage du navigateur.

<a id="use-your-own-svg-pattern"></a>
## Utiliser votre propre motif SVG

Ouvrez **Forme** → **Soulagement de l'organisateur** → **My SVGs**, chargez un SVG rempli et choisissez un motif unique ou répété. Réglez les faces, la largeur, la rotation, la position et la hauteur du relief. En répétition, seuls les motifs complets sont placés : les réduire ne laisse pas de fragments aux bords ou aux découpes. Les compartiments restent inchangés et le dessin est intégré au projet. Ouvrez **Forme** → **Couvercle** → **My SVGs** ou **Habillage** → **Pattern** → **My SVGs**. Les onglets **Couvercle** et **Habillage** partagent la bibliothèque, mais conservent des réglages indépendants. Changer d’onglet affiche la pièce seule ; si elle n’existe pas encore, l’assemblage reste visible. Vous pouvez toujours rétablir la vue d’ensemble au-dessus du modèle. Largeur, rotation, espacement et X/Y positionnent le dessin ; le bouton de centrage réinitialise position et rotation. Le couvercle accepte relief et ouvertures ; l’habillage, uniquement les ouvertures. Cadres et zones de fixation restent intacts. **×** ou **Escape** ferme le studio actif en conservant les modifications. Les flèches du clavier changent l’onglet sélectionné. Choisissez **Raised relief (decoration)** pour un relief ou **Through stencil (cut)** pour des ouvertures traversantes. Les habillages acceptent uniquement les ouvertures. La hauteur apparaît seulement en mode relief, l’espacement seulement en répétition. **Material thickness** modifie l’aperçu et l’export : 1,2–6 mm pour un couvercle SVG, 1–4 mm pour un habillage. Par défaut, le couvercle mesure 3,2 mm en relief et 2 mm en pochoir ; une épaisseur choisie est conservée au changement de mode. La hauteur du relief est comprise dans l’épaisseur. Un couvercle SVG encastré exige une profondeur intérieure au moins égale à l’épaisseur de la plaque plus 2 mm. **Supplémentaire** contient la couleur du couvercle ou les faces de l’habillage. **Which SVG files work?** explique les exigences et la préparation. [Relief SVG personnalisé](REFERENCE.md#custom-svg-relief).

<a id="print-an-entire-drawer"></a>
## Imprimer un tiroir entier

Dans **Drawer**, choisissez **Print entire drawer**. Réglez la longueur du plateau de l'imprimante (horizontale), la largeur (verticale), la hauteur de l'impression et l'espacement entre les pièces. Passez en revue le nombre de pièces, le nombre de plateaux calculés et les plans numérotés, puis choisissez **Download all beds (ZIP)**.

L'archive contient une 3MF par plateau, diagrammes de plateau, diagramme d'assemblage et copie du projet de tiroir. Ouvrir chaque 3MF comme un travail séparé dans votre slicer. Voir [Exporter tout le tiroir](REFERENCE.md#whole-drawer-export) pour plus de détails.

<a id="ready-made-stencil-examples"></a>
### Exemples de pochoirs prêts à utiliser

Télécharger [feuilles organiques](https://raw.githubusercontent.com/gromvs75/ReplixGrid/refs/heads/main/docs/examples/organic_leaf_pattern-stencil.svg) ou [hexagone double](https://raw.githubusercontent.com/gromvs75/ReplixGrid/refs/heads/main/docs/examples/3d_print_pattern-stencil.svg). Enregistrer sous `.svg`, puis télécharger à travers **My SVGs** sur le couvercle ou la habillage. Pour un couvercle choisir **Through stencil (cut)**; les habillages utilisent déjà ce mode. Choisir **Repeat** pour plusieurs copies, commencer environ 20 mm de largeur et 4 mm d'espacement, et réduire la largeur si le dessin ne correspond pas. Le fichier hexagone contient une tuile répétable; le fichier feuille contient cinq feuilles. Voir [Télécharger des pochoirs SVG prêts à utiliser](REFERENCE.md#download-ready-to-use-stencil-svgs) pour les deux surfaces et le calibrage de pont.

Les curseurs numériques affichent leurs limites réelles **Min / Max** et un marqueur de valeur blanc sur un intervalle vert autorisé. Les bouchons rouges indiquent des valeurs au-delà des limites. Vous pouvez également taper une valeur exacte.

<a id="before-uploading-an-svg"></a>
### Avant d’importer un SVG

Utilisez des SVG de 200 KB maximum contenant des contours vectoriels remplis. Convertissez le texte et les traits en contours remplis, puis supprimez les arrière-plans inutiles. Les images, masques, tracés de découpe, filtres, dégradés, blocs CSS et références à d’autres éléments ne sont pas pris en charge. Un import réussi ne garantit pas que le dessin convient à toutes les surfaces.

Le **relief** du corps et du couvercle repose sur une surface pleine. Pour des **ouvertures traversantes**, le matériau restant doit former un ensemble relié : les détails enfermés nécessitent des ponts de matière. Augmenter l’écart entre les répétitions ne fixe pas un détail isolé à l’intérieur du motif. La largeur redimensionne tout le SVG, y compris une grille déjà dessinée. En cas d’échec du calcul, l’ancienne prévisualisation peut rester affichée ; corrigez les réglages avant l’export. Voir [Choisir un SVG adapté à l’usage](REFERENCE.md#choose-an-svg-for-its-intended-use).

<a id="add-text-or-an-icon"></a>
### Ajouter du texte ou une icône

Ouvrir **Forme → Signature et badge**, choisir le côté, entrer le texte et sélectionner une police ou une étoile/cœur. Ajuster la hauteur de la lettre, la position verticale et la profondeur relevée ou gravée. Ces curseurs mettent à jour le modèle pendant que vous faites glisser; les modèles complexes se rafraîchissent au fur et à mesure que chaque calcul se termine. La hauteur de la lettre est limitée à l'espace sur le mur sélectionné sous le texte actuel. Les murs inférieurs et les découpes des autres côtés ne le limitent pas. La position verticale passe du bas (0 %) à la position la plus haute en toute sécurité sous l'ouverture ou la découpe (100 %). Sur les modèles circulaires et ovales, l'inscription suit le mur courbé et est incluse dans l'exportation d'impression.

<a id="relief-on-stacked-trays"></a>
### Relief sur les plateaux empilés

Dans le menu à côté de **Organiseur**, au-dessus du modèle, choisissez l’étage à modifier. Ouvrez **Forme** → **Soulagement de l'organisateur** et sélectionnez un motif intégré ou un SVG. Chaque étage peut avoir son propre relief. Le décor reste sur les parois extérieures ; les rebords d’emboîtement, languettes et logements restent lisses. Les dimensions intérieures sont conservées. Les exports STL et 3MF incluent le relief et les pièces séparées de chaque étage. Vérifiez l’ajustement avec un petit essai lorsque vous changez d’imprimante ou de matériau.

<a id="manage-filament-slots"></a>
### Gérer les emplacements de filament

Dans **Impression** → **Slicer filaments**, utilisez les mêmes numéros et couleurs que dans le slicer. Sur Snapmaker U1, les emplacements 1–4 correspondent aux têtes T0–T3. Vous pouvez configurer jusqu’à 16 emplacements, avec couleur et nom de matériau. La couleur sert de repère approximatif ; elle ne simule pas la teinte imprimée ou mélangée. Réglez les mélanges exacts dans le slicer. Sélectionnez une carte puis **Delete filament from slot N** pour supprimer le filament. Les autres numéros restent inchangés : supprimer l’emplacement 6 laisse le 7 au numéro 7. **+ Slot N** réutilise le plus petit numéro libre ; la limite reste 16. La suppression ne change pas la couleur du modèle. Les emplacements supprimés ne sont plus proposés ni associés automatiquement à l’export ; choisissez-en un autre ou affectez-le dans le slicer. Des couleurs distinctes permettent l’association automatique. Si deux emplacements ont la même couleur, choisissez celui voulu pour chaque pièce dans la fenêtre de téléchargement.

Pour reprendre une couleur numérique du slicer, saisissez le **HEX code** à six caractères, par exemple `#E63522`, près du sélecteur de couleur. Le `#` initial est facultatif. Un code valide actualise immédiatement l’aperçu. Une saisie incomplète ou incorrecte n’est pas appliquée ; la couleur enregistrée revient en quittant le champ. Ce code ne simule ni l’aspect réel du filament, ni l’éclairage, ni le mélange physique des couleurs.
