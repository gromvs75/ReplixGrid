# 制作您的第一个 ReplixGrid 收纳盒

<a id="first-visit-and-a-clean-start"></a>
## 首次启动与新建项目

首次启动时，工作区为空。左侧向导分为三个步骤：**选择形状 → 设置尺寸 → 添加隔间**。选择形状并设置尺寸后，点击**下一步：隔间**，最后选择**完成**或**不添加隔板**。选好形状后，也可以点击**×**关闭向导。您还可以打开已保存的项目或 JSON 文件。

**在小屏幕上：**当浏览器窗口宽度不超过 1400 px 时，助手会显示在**模型下方**，避免遮挡预览。请**向下滚动页面**，查看助手、后续步骤以及进入隔间设置和完成操作的按钮。向上滚动即可再次查看模型。在更宽的窗口中，助手仍位于左侧菜单旁。

通过**帮助 → 向导：三个步骤**可再次打开向导。打开向导不会改变模型；选择其他形状会替换当前模型，此操作可以撤销。

快速入门、用户指南和帮助菜单使用当前界面语言。视频仍为英语。

向导中的步骤、提示和保存确认均已翻译。已保存模型的条目显示为**上一个项目**。**我的项目**中的实际项目名称保持保存时的原样。

点击顶部的**新建项目**即可从空白工作区开始。此前的工作（包括未命名的草稿）会保存在**我的项目**中。点击带缩略图的**上一个项目**条目可打开项目库。工作区立即清空，直到您选择新的形状。新模型没有隔板或配件；蜂窝形状保留相连的单元格。打开已保存项目会恢复其模型。**形状 → 基础**中的模板会修改当前项目，而**新建项目**会创建独立项目。


[打开 ReplixGrid](https://grid.replixcast.com/?lang=zh-CN) [用户指南](REFERENCE.md)

从您的办公桌的三块组织器开始。 下面的例子为 180 × 90 毫米, 正面低, 便于访问, 背高。 您只需要设计一个浏览器。 要为打印机准备文件, 请在您通常的切片器中打开它 。

[以英语观看快速启动视频 (1:03)](https://grid.replixcast.com/guides/quick-start-en.mp4),看如何分割一个隔间,俯瞰顶端边缘,增加一个双托盖,并导出一个3MF.

<a id="find-your-controls"></a>
## 找到所需的控件

- **左上边 :** 选择**形状** 、**分格** 、**外壳** 或**打印** 。左方菜单列出该工具的章节。
- **预览底部 :** 选择一个区域打开一个紧凑、浮动的设置编辑器。 场景和网格继续其背后. 此处仅显示所选部分 。 使用切夫龙来崩溃它,或者 **×** 以关闭它;选择左边的另一节以继续。
- **在模型上方,在中央:** **组装视图** , **收纳盒** , **内衬** , **外壳** 财务报告和财务报告 **盖子** 控制你看到的哪个部分。 对于堆叠式设计,请使用旁边的级降 **收纳盒** 在不关闭底端设置编辑器的情况下选择活动级别。 选择 **查看堆栈** 在同一滴滴中,看到所有层次和附件在一起。 可用的按钮取决于您的设计 。 在较窄的窗口上,它们会移动到工具栏下方的单独的一行.
- **在右边:** 单击区间编号、墙壁或分隔符,以编辑该元素。

在**形状**中,从**底部形状**开始,然后使用**尺寸**. 在**外壳**中,选择图案,外壳类型,颜色,厚度/边沿,并适合其单独的部分. 在**打印**中,选择打印机,配置丝线槽,或者打开区块打印控制器.

在移动滑动器时,模型会随着每次计算完成而更新. 复杂的模型可能需要更长的时间;最终值总是完全精确地计算. 在检查或导出结果之前等待完成的预览 。 编辑器通知在10秒后消失, 或者您可以关闭它们 。 **×** .

Quick Start 视频是用先前的面板布局录制的。 建模步骤仍然适用; 使用以上位置来查找当前控件 。

<a id="build-the-example"></a>
## 按示例制作

1. **打开** [grid.replixcast.com](https://grid.replixcast.com/?lang=zh-CN). 使用顶端栏的语言菜单来更改语言。 如果您已经有设计要保留, 请点击 **保存项目** 在开始前下载可编辑的副本 。
2. **创造体.** 打开 **形状** , 在 **胶囊** 下选择 **底部形状** , 在 **斜坡** 下选择 **高度轮廓** , 然后点击 **从模板创建** 。 预览应显示两个分隔符和三个编号的分隔符。 边框从 22 毫米升至 70 毫米。 创建一个模板来取代当前设计; 弯曲的撤销箭头还原它 。
3. **适合你的空间。** 在 **形状 → 尺寸** 下, 输入外部宽度和深度, 以毫米计。 单击一个编号的区块来读取其内部尺寸 。 在 **内部尺寸** 下, 输入所需的宽度或深度, 或单击模型上的蓝色尺寸标签, 并键入值。 点击外部即可应用 。 从区块 1 开始, 按简单行顺序工作; 最后一个区块接收剩余部分 。 圆形端可以缩小到测量线, 因此检查对象脚印并离开清除 。
4. **需要时调整布局 。** 切换到 **俯视**, 选择一个隔间, 设置 **零件数量** 到 **2**, 然后点击 **宽度分割** 或 **分为深度**。 只单击选定的隔间分割 。 单击分隔器以调整其位置, 或从 **所有墙壁和隔间** 在右面板中选择一个元素 。 移动选中的分隔器会改变两侧的隔间, 同时保留其他分隔器位置 。 返回 **3D** 检查结果 。

5. **完成顶端边缘( 可选) 。** 下级 **形状 → 拐角和倒角** 时,查找 **外壁与隔板的顶边** . 选择 **倒角** 用于平坦的贝壳或 **圆角矩形** 对于一个弯曲的边缘。 输入尺寸,以毫米计;最大值取决于壁厚,所以平整的条块仍留在顶部。 尾部沿外墙两侧和分隔器. 选择 **无** 以恢复正方形边缘。 当将剪切,内角圆形和斜面或倾斜的车体组合在一起时,等待完成的预览后再下载. 请检查access-date=中的日期值 (帮助) 下载对话框中的最后维度:倾斜可以增加外部足迹. 单个蜂窝边缘的剪切不支持.

## 下载第一个打印模型

1. 打开 **打印** 并选择您的打印机配置或输入其构建音量。
2. 单击 **↓ 下载** 在顶端的栏杆。 内 **检查并下载** 选择 **整理器和配件** . 如果你加了一个外壳,也想要它,就选择整个包.
3. 选择 **STL** 用于单色体, 或 **3MF** 以保留单独的部件、 颜色和丝线任务。 等待几何和大小检查。 如果某个部分不合适, 请校正尺寸或构建音量并重新打开对话框 。
4. 单击 **下载 STL** 或 时 间 **下载 3MF** 在对话框的底部。 若数 STL 编 文件到达 a ZIP 先取出来
5. 打开您切片机中的模型。 请检查其大小, 以毫米计, 将组织器基座放置在床上, 并安排任何单独的部件 。 请在打印前选择您的打印机和材料配置、 切片, 并检查第一层和图层预览中的分隔符 。

<a id="projects-and-backups"></a>
## 项目与备份

打开 **我的项目** 并保存一个命名的复制件。 打开的工程会自动保存。 您也可以在那里搜索、 重命名、 打开、 删除或下载工程。 未命名的工作会被保留为草稿 。 将工程 JSON 文件下载为备份或传输, 在顶端栏点击 **打开** 以加载它。 损坏的文件应该报告验证错误而不替换当前工程 。

应用编辑立即被保存。 如果写入中断, 重新打开应用程序会恢复其临时恢复副本。 如果当前会话损坏, 应用程序会尝试其上次成功快照。 当无法恢复副本时, 自动保存停止以保护存储的数据; 使用 **打开** 恢复已下载的 JSON 备份。 如果保存错误, 在离开前下载工程备份 。

导出检查使用最新的应用编辑器和选中的部分。 在修改尺寸或挂起位置后, 在下载前等待新的检查 。

当同一个工程或抽屉被编辑到多个标签中时, 相互冲突的更改会被保存为单独的 **Copy from another tab** 。 另一个版本被保存, 编辑标签继续复制。 比较 **我的项目** 或抽屉选择器中的版本, 并重命名副本, 如果您想要保存的话。 重新打开一个组织者标签会恢复它自己保存的工程。 更改不会在标签中自动合并 。

库存储在您的浏览器中, 并绑定在站点地址上。 清除站点数据或更改浏览器、 设备或地址可以使其无法使用。 保存一个单独的工程文件备份。 文件夹插槽被单独存储在浏览器中, 而不包含在 JSON 项目中; 在另一个设备上再次配置 。

<a id="filaments-and-export-options"></a>
## 耗材与导出格式

对于多颜色的 3MF , 请在 **打印** 中配置可用的槽, 其数量和颜色与您的切片器相同。 在 Snapmaker U1 上, 前四个对应 T0– T3. 在下载对话框中为每个部分指定一个槽, 然后验证 Snapmaker Orca 中的任务。 未指定的部件可能使用第一个丝。 您的打印机和材料配置来自您的切片器 。

对于彩色的 OBJ , 请将 OBJ 及其 MTL 文件保存在同一文件夹中。 导出检查允许在床边为每个部分设置2毫米的边距。 安排整个包, 检查切片器中的悬浮和细细细节 。

<a id="print-a-large-organizer-in-sections"></a>
## 分段打印大型收纳盒

在 **打印** 中, 设置构造体积并选择两或三节, 或使用建议的剪切。 应用程序将壁厚至少提升到5毫米, 地板厚度至少提升到3毫米, 改变隔间大小 。 拆分时没有贝壳和插入; 应用程序提示您删除它们。 有些形状和设置也限制拆分 。

下载联合样本,将其一半分开放置,并按100%的比例打印。一旦冷却,就检查针头的套装。然后下载套装,检查切片机中的所有部件,打印它们,并在使用针头和胶水冷却后组装它们。名义的针头尺寸为3.2×8毫米;每个孔孔深为3.3毫米和4.5毫米。适合和强度取决于打印设置、材料和胶水质量。

<a id="shells"></a>
## 外壳

Dense shell 模式需要几秒钟才能重新计算。 如果一个 shell 无法构建, 成功构建的组织器仍然可见, 错误仍然可用; 这无法使 shell 准备好打印 。 纠正 shell 设置并再次运行下载检查 。 导出仍然验证请求的每个部分 。

在组织器身周围建了一个单件装饰壳。 当将一个外壳图案加到有底端修剪的堆叠组织器上时, 应用程序会自动选择一个单件外壳; 修剪仍保留在第一层。 要使用单独的面板, 打开**外壳 → shell 类型 → 装饰板**。 面板会保留壁厚度和隔板尺寸。 使用2.4 mm的墙壁和2 mm的地板, 将**隐藏的紧身裤** 关闭并粘贴到位的面板。 隐藏的紧贴板需要壁厚至少3.2 mm的厚度而无需松动 。 面板的底部坐落在剪贴板上; **边缘偏移** 起于顶部, 并且必须至少3mm 位于堆叠的托盘上 。 遗留的剪接装置和地板薄度大于 1.2 mm的薄度不能与壳支持的底部的剪合在一起 。 检查预览和切器输出, 在打印一个小印后, 。

## 沿用其他收纳盒的样式

使用 **形状 → 通用样式** 以名称保存当前颜色和模式。打开另一个工程,选择保存样式,并点击 **应用样式**。您可以在保留目的地的尺寸和隔间的同时,传输颜色、模式或两者。关于兼容性和浏览器存储细节,请参见 [共享样式](REFERENCE.md#shared-styles) 。

<a id="use-your-own-svg-pattern"></a>
## 使用自己的 SVG 图案

打开 **形状 → 收纳盒浮雕 → My SVGs** ,上传已填充 SVG ,并选择一个函数或重复模式。 选择墙壁,设置宽度,旋转和位置,然后调整救援深度. 在重复模式中,只放置完整的motifs:减小宽度不会在边缘或剪切处留下被剪断的碎片. 内部隔间保持不变。 模式嵌入了保存的工程中. 同一图书馆在 **形状 → 盖子 → My SVGs** (提高模式或通过开口)和 **外壳 → 图案 → My SVGs** (经论). 对于盖子和贝壳, **My SVGs** 打开底部 **图案工作室** . 使用它 。 **立德/ 壳牌** 选项卡,用于切换表面,并自动隔离预览中的相应部分。 图书馆位于左侧;大小、旋转、间隔和X/Y相冲均与图书馆并列。 选择 **提高救济(勋章)** 或 时 间 **通过stencil(剪切)** 在右手设置的顶端。 救援高度仅用于救援;重复间隔仅用于重复模式。 **材料厚度** 改变生成的板块(1.2-6毫米用于 SVG 盖,1–4毫米用于罐壳). 现存的盖默认值为松动3.2毫米,齿轮2毫米;切换模式时会保留明确选择的厚度. 一个内置 SVG 盖子需要至少其厚度+2毫米的内部深度. 贝壳图案总是切穿壳体,所以那里没有解脱. 底色在下边 **附加** ; 文件要求列在下面 **哪个 SVG 文件有效 ?** . 关闭工作室 保持您的零钱。 框架和配具表面保留下来。 切口时,在任何封闭的内部细节中加入桥梁,以便保持连接。 见 [自定义 SVG 浮雕](REFERENCE.md#custom-svg-relief) 用于支持的文件和限制。

<a id="print-an-entire-drawer"></a>
## 打印整个抽屉

在 **DRAWER** 中, 选择 **Print entire drawer**. 设置打印机床位长度( 横向), 宽度( 垂直) , 打印高度和各部分之间的间隔 。 审查部分数, 计算床位数和编号布局, 然后选择 **Download all beds (ZIP)**。

档案中包含一张每张床的3MF、一张床图、一张组装图和一份抽屉项目副本。打开每张3MF作为您切片机中的一项单独工作。详情见[导出整个抽屉](REFERENCE.md#whole-drawer-export)。

### 可直接使用的镂空模板示例

下载 [有机叶](https://raw.githubusercontent.com/gromvs75/ReplixGrid/refs/heads/main/docs/examples/organic_leaf_pattern-stencil.svg) 或 [双六边形](https://raw.githubusercontent.com/gromvs75/ReplixGrid/refs/heads/main/docs/examples/3d_print_pattern-stencil.svg) 。 保存为 `.svg` , 然后通过 **My SVGs** 上传到盖或壳上。 对于盖子, 选择 **通过stencil(剪切)** ; 贝壳已经使用该模式。 选择 **Repeat** 为多份副本, 从20毫米宽度和4毫米间距开始, 如果绘图不合适则缩小宽度 。 六边形文件包含一个可重复的瓦片; 叶片包含五个叶片 。 请参看 [下载可直接使用的 SVG 镂空模板](REFERENCE.md#download-ready-to-use-stencil-svgs) 。

数字滑动显示其实际的**最小/ 最大值** 限制和绿色允许间隔上的白色值标记。红色端盖表示超出限制的值。您也可以输入一个精确的值。

<a id="before-uploading-an-svg"></a>
### 上传 SVG 前的准备

使用最多 200 KB 的填充矢量轮廓 。 转换文本和划线来勾画和删除任何不想要的背景 。 不支持图像、 面具、 剪辑、 过滤器、 梯度、 CSS 样式块和元素引用 。 导入的文件并不自动适合每个表面 。

机身和盖子 **救济** 有坚实的支撑。 **通过开口** 必须留下连接的材料: 封装细节需要刻度桥。 增加重复间隔不能固定绘图内部的孤立细节。 宽度缩放整个 SVG, 包括其中已绘制的网格。 如果一个构建失败, 则最后一个成功预览会保留; 在导出前纠正设置 。 请参看 [根据用途选择 SVG](REFERENCE.md#choose-an-svg-for-its-intended-use) , 用于准备步骤和示例 。

<a id="add-text-or-an-icon"></a>
### 添加文字或图标

打开 **形状 → 文字与图标**, 选择侧面、 输入文本并选择字体或恒星/ 心脏。 调整字母高度、 垂直位置、 升起或刻入深度 。 这些滑块在拖动时更新模型; 复杂的模型在每次计算完成时刷新。 字母高度仅限于当前文本下方选定墙上的空间。 下方的墙壁和剪切并不限制它。 垂直位置从下方( 0%) 到打开或剪切( 100%) 下方的最高安全位置 。 在圆形和椭圆形模型上, 铭文沿着曲线墙并包含在打印导出中。 如果不合适, 则缩短文本或降低字母高度 。

<a id="relief-on-stacked-trays"></a>
### 多层托盘上的浮雕

选择 **第 1 层**, **第 2 层**, 或者在模型上方**收纳盒** 旁边的下拉层, 然后打开 **形状 → 收纳盒浮雕** 来选择内置图案或您的 SVG 。 每层可以有自己的解脱。 装饰保留在外墙上, 没有平滑的交配项圈、 舌头和插座。 内部隔间尺寸保持不变。 STL 和 3MF 输出包括解脱和保留单独的可打印的分级部件。 在更换打印机或材料时用小的试印来验证物理是否适合 。

<a id="manage-filament-slots"></a>
### 管理耗材槽位

在**打印 → 切片软件耗材**中添加最多 16 个槽位，为每个槽位设置名称和用于预览的大致颜色。精确颜色和混色请在切片软件中设置；ReplixGrid 不计算混色配方。选择任意耗材卡片并点击**删除槽位 N 的耗材**，即可释放该编号，其余槽位不会重新编号。**+ 槽位 N**恢复最小的空闲编号。模型颜色不变。导出 3MF 前，请再次检查耗材分配，尤其是在删除耗材之后。

为了配合你的切片机的数码颜色, 粘贴它的六位数 **HEX 代码** ,例如, `#E63522` 在采色器旁边 领先者 `#` 是可选的。 有效的代码立即更新预览;不应用不完整或无效的文本,并在退出字段时返回保存的颜色. 一个匹配 HEX 代码不模拟丝状外观、照明或物理颜色混合物。
