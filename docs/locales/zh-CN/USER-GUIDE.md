# 制作您的第一个 ReplixGrid 收纳盒

<a id="first-visit-and-a-clean-start"></a>
## 首次启动与新建项目

首次启动时，工作区为空。左侧向导分为三个步骤：**选择形状 → 设置尺寸 → 添加隔间**。选择形状并设置尺寸后，点击**下一步：隔间**，最后选择**完成**或**不添加隔板**。选好形状后，也可以点击**×**关闭向导。您还可以打开已保存的项目或 JSON 文件。

**在小屏幕上：**当浏览器窗口宽度不超过 1400 px 时，助手会显示在**模型下方**，避免遮挡预览。请**向下滚动页面**，查看助手、后续步骤以及进入隔间设置和完成操作的按钮。向上滚动即可再次查看模型。在更宽的窗口中，助手仍位于左侧菜单旁。

通过**帮助 → 向导：三个步骤**可再次打开向导。打开向导不会改变模型；选择其他形状会替换当前模型，此操作可以撤销。

快速入门、用户指南和帮助菜单使用当前界面语言。视频仍为英语。

向导中的步骤、提示和保存确认均已翻译。已保存模型的条目显示为**上一个项目**。**我的项目**中的实际项目名称保持保存时的原样。

点击顶部的**新建项目**即可从空白工作区开始。此前的工作（包括未命名的草稿）会保存在**我的项目**中。点击带缩略图的**上一个项目**条目可打开项目库。工作区立即清空，直到您选择新的形状。新模型没有隔板或配件；蜂窝形状保留相连的单元格。打开已保存项目会恢复其模型。**形状 → 底部形状**中的模板会修改当前项目，而**新建项目**会创建独立项目。


[打开 ReplixGrid](https://grid.replixcast.com/?lang=zh-CN) [用户指南](REFERENCE.md)

从您的办公桌的三块收纳盒开始。 下面的例子为 180 × 90 毫米, 正面低, 便于访问, 背高。 您只需要设计一个浏览器。 要为打印机准备文件, 请在您通常的切片软件中打开它 。

[以英语观看快速启动视频 (1:03)](https://grid.replixcast.com/guides/quick-start-en.mp4),看如何分割一个隔间,俯瞰顶端边缘,增加一个双托盖,并导出一个3MF.

<a id="find-your-controls"></a>
## 找到所需的控件

- **左上边 :** 选择**形状** 、**分格** 、**外壳** 或**打印** 。左方菜单列出该工具的章节。
- **预览底部 :** 选择一个区域打开一个紧凑、浮动的设置编辑器。 场景和网格继续其背后. 此处仅显示所选部分 。 使用切夫龙来崩溃它,或者 **×** 以关闭它;选择左边的另一节以继续。
- **模型上方：**选择 **组装视图**、**收纳盒**、**内衬**、**外壳** 或 **盖子**。**收纳盒** 旁的菜单可选择单层编辑，或用 **查看堆栈** 查看整套堆叠模型，底部编辑面板保持打开。按钮是否可用取决于已有零件；窄窗口中按钮会移到单独一行。
- **右侧：**点击隔间编号、壁面或隔板，即可打开对应设置。

在**形状**中,从**底部形状**开始,然后使用**尺寸**. 在**外壳**中,选择图案,外壳类型,颜色,厚度/边沿,并适合其单独的部分. 在**打印**中,选择打印机,配置丝线槽,或者打开区块打印控制器.

拖动滑块时，模型会在每次计算完成后更新。复杂模型可能需要更长时间，但最终值始终按完整精度计算。请等预览更新完成后再检查或导出。通知会在 10 秒后消失，也可点击 **×** 关闭。

Quick Start 视频是用先前的面板布局录制的。 建模步骤仍然适用; 使用以上位置来查找当前控件 。

<a id="build-the-example"></a>
## 按示例制作

1. **打开** [grid.replixcast.com](https://grid.replixcast.com/?lang=zh-CN). 使用顶端栏的语言菜单来更改语言。 如果您已经有设计要保留, 请点击 **保存项目** 在开始前下载可编辑的副本 。
2. **创造体.** 打开 **形状** , 在 **胶囊** 下选择 **底部形状** , 在 **斜坡** 下选择 **高度轮廓** , 然后点击 **从模板创建** 。 预览应显示两个分隔符和三个编号的分隔符。 边框从 22 毫米升至 70 毫米。 创建一个模板来取代当前设计; 弯曲的撤销箭头还原它 。
3. **适合你的空间。** 在 **形状 → 尺寸** 下, 输入外部宽度和深度, 以毫米计。 单击一个编号的区块来读取其内部尺寸 。 在 **内部尺寸** 下, 输入所需的宽度或深度, 或单击模型上的蓝色尺寸标签, 并键入值。 点击外部即可应用 。 从区块 1 开始, 按简单行顺序工作; 最后一个区块接收剩余部分 。 圆形端可以缩小到测量线, 因此检查对象脚印并离开清除 。
4. **需要时调整布局 。** 切换到 **俯视**, 选择一个隔间, 设置 **零件数量** 到 **2**, 然后点击 **分割 沿宽度** 或 **分割 沿深度**。 只单击选定的隔间分割 。 单击分隔器以调整其位置, 或从 **所有墙壁和隔间** 在右面板中选择一个元素 。 移动选中的分隔器会改变两侧的隔间, 同时保留其他分隔器位置 。 返回 **三维** 检查结果 。

5. **完成顶端边缘( 可选) 。** 下级 **形状 → 拐角和倒角** 时,查找 **外壁与隔板的顶边** . 选择 **倒角** 用于平坦的外壳或 **圆角** 对于一个弯曲的边缘。 输入尺寸,以毫米计;最大值取决于壁厚,所以平整的条块仍留在顶部。 尾部沿外墙两侧和分隔器. 选择 **无** 以恢复正方形边缘。 当将剪切,内角圆形和斜面或倾斜的车体组合在一起时,等待完成的预览后再下载. 请检查access-date=中的日期值 (帮助) 下载对话框中的最后维度:倾斜可以增加外部足迹. 单个蜂窝边缘的剪切不支持.

## 试用双色盖子

盖子要求顶边高度一致。如需保留示例中的斜顶胶囊形模型，请先用 **保存项目** 下载备份。然后在 **形状** 中选择 **胶囊** 和 **等高** 高度轮廓，再点击 **从模板创建**。

1. 打开 **形状 → 盖子** 并增加一个盖子。 在 **盖子配合方式** 下, 选择 **外盖式** , 用于覆盖轮廓的盖子, 或 **内嵌式** , 用于坐落在其内部冲压的盖子。 双托式内置盖子需要至少2毫米厚的墙壁, 内部深度至少5.2毫米 。
2. 启用 **双色图案** 选择一个 **Lid pattern** . 为了尝试画廊中的扇形叶子,选择 **银杏叶** .
3. 设定 **盖子底色** 背景颜色和 **盖子图案颜色** 改为绘图的颜色。 对于下面所示的组合,选择基部的奶油和图案的橄榄绿色.

在底色、图案和把手的颜色弹窗中选择 **切片软件耗材**。请先到 **打印 → 切片软件耗材** 设置槽位。**与盖子底色相同** 使把手跟随底色；选择其他颜色即可独立设置。导出为 3MF 以保留颜色，并核对耗材分配。

![双托盖,从左到右,顶排显示橄榄枝,金戈叶和Fern frond,底排显示潮汐波,河石和生长环.](../../images/lid-motifs.svg)

**双色图案** 适用于两种盖子。可选择橄榄枝、银杏叶、蕨叶、波浪、河卵石、年轮或 Voronoi 单元，并设置底色和图案色。3.2 mm 厚的板由 1.6 mm 实心底层和 1.6 mm 图案层组成；外盖定位边及把手会增加总高度。内嵌盖要求内部深度至少 5.2 mm。导出 3MF 可保持两个彩色部分的相对位置，再为各部分分配耗材。橄榄枝、银杏叶、蕨叶、波浪和年轮的 **镂空图案** 会在上层形成开口。启用 **浮雕图案** 后，深 1.6 mm 的开口保持空置，露出下方底层；关闭后则形成平整的镶嵌效果。内嵌浮雕盖应底层朝下打印，外盖应图案面朝下打印。请在切片软件中检查凹处上方的桥接。

## 下载第一个打印模型

1. 打开 **打印** 并选择您的打印机配置或输入其模型计算音量。
2. 单击 **↓ 下载** 在顶端的栏杆。 内 **检查并下载** 选择 **整理器和配件** . 如果你加了一个外壳,也想要它,就选择整个包.
3. 选择 **STL** 用于单色体, 或 **3MF** 以保留单独的部件、 颜色和丝线任务。 等待几何和大小检查。 如果某个部分不合适, 请校正尺寸或模型计算音量并重新打开对话框 。
4. 单击 **↓ 下载 STL** 或 时 间 **↓ 下载 3MF** 在对话框的底部。 若数 STL 编 文件到达 a ZIP 先取出来
5. 在切片软件中打开模型，确认尺寸单位为毫米。将收纳盒底面放在打印平台上，并摆放其他零件。选择打印机和材料配置，完成切片后检查首层与隔板的逐层预览，再开始打印。

<a id="projects-and-backups"></a>
## 项目与备份

打开 **我的项目**，保存一份有名称的副本。当前项目会自动保存；库中也可搜索、重命名、打开、删除或下载项目。未命名的工作会保留为草稿。下载 JSON 可用于备份或迁移，再用顶部的 **打开** 载入。损坏的文件应显示校验错误，而不替换当前项目。

应用编辑立即被保存。 如果写入中断, 重新打开应用程序会恢复其临时恢复副本。 如果当前会话损坏, 应用程序会尝试其上次成功快照。 当无法恢复副本时, 自动保存停止以保护存储的数据; 使用 **打开** 恢复已下载的 JSON 备份。 如果保存错误, 在离开前下载工程备份 。

导出检查使用最新的应用编辑器和选中的部分。 在修改尺寸或挂起位置后, 在下载前等待新的检查 。

当同一个工程或抽屉被编辑到多个标签中时, 相互冲突的更改会被保存为单独的 **Copy from another tab** 。 另一个版本被保存, 编辑标签继续复制。 比较 **我的项目** 或抽屉选择器中的版本, 并重命名副本, 如果您想要保存的话。 重新打开一个组织者标签会恢复它自己保存的工程。 更改不会在标签中自动合并 。

库存储在您的浏览器中, 并绑定在站点地址上。 清除站点数据或更改浏览器、 设备或地址可以使其无法使用。 保存一个单独的工程文件备份。 文件夹插槽被单独存储在浏览器中, 而不包含在 JSON 项目中; 在另一个设备上再次配置 。

<a id="filaments-and-export-options"></a>
## 耗材与导出格式

导出多色 3MF 前，在 **打印** 中设置与切片软件相同的耗材槽编号和颜色。Snapmaker U1 的前四槽对应 T0–T3。在下载窗口为每个零件分配耗材槽，再到 Snapmaker Orca 中核对。未分配的零件可能使用第一种耗材。打印机和材料配置仍需在切片软件中选择。

对于彩色的 OBJ , 请将 OBJ 及其 MTL 文件保存在同一文件夹中。 导出检查允许在平台边缘为每个部分设置2毫米的边距。 安排整个包, 检查切片软件中的悬浮和细细细节 。

<a id="print-a-large-organizer-in-sections"></a>
## 分段打印大型收纳盒

在 **打印** 中设置打印空间，然后选择两段、三段或建议的分割方式。分割会将壁厚增至至少 5 mm、底厚增至至少 3 mm，因此隔间尺寸会改变。应用会要求先移除外壳和内衬；部分形状和设置不支持分割。

下载联合样本,将其一半分开放置,并按100%的比例打印。一旦冷却,就检查针头的套装。然后下载套装,检查切片软件中的所有部件,打印它们,并在使用针头和胶水冷却后组装它们。名义的针头尺寸为3.2×8毫米;每个孔孔深为3.3毫米和4.5毫米。适合和强度取决于打印设置、材料和胶水质量。

<a id="shells"></a>
## 外壳

Dense shell 模式需要几秒钟才能重新计算。 如果一个 shell 无法模型计算, 成功模型计算的收纳盒仍然可见, 错误仍然可用; 这无法使 shell 准备好打印 。 纠正 shell 设置并再次运行下载检查 。 导出仍然验证请求的每个部分 。

在收纳盒身周围建了一个单件装饰壳。 当将一个外壳图案加到有底端修剪的堆叠收纳盒上时, 应用程序会自动选择一个单件外壳; 修剪仍保留在第一层。 要使用单独的面板, 打开**外壳 → Тип оболочки → 装饰板**。 面板会保留壁厚度和隔板尺寸。 使用2.4 mm的墙壁和2 mm的底面, 将**隐藏坐骑** 关闭并粘贴到位的面板。 隐藏的紧贴板需要壁厚至少3.2 mm的厚度而无需松动 。 面板的底部坐落在剪贴板上; **边缘偏移** 起于顶部, 并且必须至少3mm 位于堆叠的托盘上 。 遗留的剪接装置和底面薄度大于 1.2 mm的薄度不能与壳支持的底部的剪合在一起 。 检查预览和切器输出, 在打印一个小印后, 。


<a id="match-another-organizer"></a>
## 沿用其他收纳盒的样式

使用 **形状 → 通用样式** 以名称保存当前颜色和模式。打开另一个工程,选择保存样式,并点击 **应用样式**。您可以在保留目的地的尺寸和隔间的同时,传输颜色、模式或两者。关于兼容性和浏览器存储细节,请参见 [共享样式](REFERENCE.md#shared-styles) 。

<a id="use-your-own-svg-pattern"></a>
## 使用自己的 SVG 图案

打开 **形状** → **收纳盒浮雕** → **My SVGs**，上传有填充轮廓的 SVG，再选择单个图案或重复排列。设置壁面、宽度、旋转、位置和浮雕高度。重复模式只放置完整图案，缩小图案不会在边缘或缺口留下残片。隔间内部不变，图案会保存到项目中。 打开 **形状** → **盖子** → **My SVGs** 或 **外壳** → **Pattern** → **My SVGs**。**盖子** 和 **外壳** 选项卡共用图案库，但设置互相独立。切换选项卡会单独显示相应零件；尚未添加该零件时，仍显示组装模型。也可在模型上方手动选择组装视图。宽度、旋转、间距和 X/Y 控制图案放置；居中按钮重置位置和旋转。盖子支持浮雕及通孔，外壳只支持通孔；边框和安装区域会保留。在工作室获得焦点时，按 **×** 或 **Escape** 关闭，修改仍会保存。方向键可切换已聚焦的选项卡。 选择 **Raised relief (decoration)** 制作浮雕，或 **Through stencil (cut)** 制作通孔。外壳仅支持通孔。浮雕高度仅在浮雕模式显示，间距仅在重复模式显示。**Material thickness** 同时改变预览和导出：SVG 盖子为 1.2–6 mm，外壳为 1–4 mm。默认厚度为浮雕 3.2 mm、模板 2 mm；手动设置的厚度在切换模式后保留。浮雕高度已计入盖子厚度。内嵌 SVG 盖子要求内部深度至少为板厚加 2 mm。**附加** 提供盖子颜色或外壳壁面选择，**Which SVG files work?** 说明文件要求及准备方法。 [自定义 SVG 浮雕](REFERENCE.md#custom-svg-relief).

<a id="print-an-entire-drawer"></a>
## 打印整个抽屉

在 **Drawer** 中, 选择 **Print entire drawer**. 设置打印机打印平台长度( 横向), 宽度( 垂直) , 打印高度和各部分之间的间隔 。 审查部分数, 计算打印平台数和编号布局, 然后选择 **Download all beds (ZIP)**。

档案中包含一张每张打印平台的3MF、一张床图、一张组装图和一份抽屉项目副本。打开每张3MF作为您切片软件中的一项单独工作。详情见[导出整个抽屉](REFERENCE.md#whole-drawer-export)。

<a id="ready-made-stencil-examples"></a>
### 可直接使用的镂空模板示例

下载 [有机叶](https://raw.githubusercontent.com/gromvs75/ReplixGrid/refs/heads/main/docs/examples/organic_leaf_pattern-stencil.svg) 或 [双六边形](https://raw.githubusercontent.com/gromvs75/ReplixGrid/refs/heads/main/docs/examples/3d_print_pattern-stencil.svg) 。 保存为 `.svg` , 然后通过 **My SVGs** 上传到盖或壳上。 对于盖子, 选择 **Through stencil (cut)** ; 外壳已经使用该模式。 选择 **Repeat** 为多份副本, 从20毫米宽度和4毫米间距开始, 如果绘图不合适则缩小宽度 。 六边形文件包含一个可重复的瓦片; 叶片包含五个叶片 。 请参看 [下载可直接使用的 SVG 镂空模板](REFERENCE.md#download-ready-to-use-stencil-svgs) 。

数字滑动显示其实际的**Min / Max** 限制和绿色允许间隔上的白色值标记。红色端盖表示超出限制的值。您也可以输入一个精确的值。

<a id="before-uploading-an-svg"></a>
### 上传 SVG 前的准备

使用不超过 200 KB、包含填充矢量轮廓的 SVG。请先把文字和描边转换为填充轮廓，并删除不需要的背景。不支持图片、蒙版、裁剪路径、滤镜、渐变、CSS 样式块和对其他元素的引用。导入成功并不代表图案适合所有表面。

盒体和盖子的**浮雕**由完整底面支撑。盖子或外壳的**通孔**则必须保证剩余材料相互连通；封闭的内部细节需要连接桥。增大重复间距无法固定图案内部的独立细节。宽度会缩放整个 SVG，包括文件中已有的图案阵列。计算失败时可能仍显示上一次成功的预览，请先修正设置再导出。准备方法和示例见[根据用途选择 SVG](REFERENCE.md#choose-an-svg-for-its-intended-use)。

<a id="add-text-or-an-icon"></a>
### 添加文字或图标

打开 **形状 → 文字与图标**, 选择侧面、 输入文本并选择字体或恒星/ 心脏。 调整字母高度、 垂直位置、 升起或刻入深度 。 这些滑块在拖动时更新模型; 复杂的模型在每次计算完成时刷新。 字母高度仅限于当前文本下方选定墙上的空间。 下方的墙壁和剪切并不限制它。 垂直位置从下方( 0%) 到打开或剪切( 100%) 下方的最高安全位置 。 在圆形和椭圆形模型上, 铭文沿着曲线墙并包含在打印导出中。 如果不合适, 则缩短文本或降低字母高度 。

<a id="relief-on-stacked-trays"></a>
### 多层托盘上的浮雕

在模型上方 **收纳盒** 旁的菜单中选择要编辑的层，再打开 **形状** → **收纳盒浮雕**，选择内置图案或 SVG。每层可使用独立浮雕。装饰仅位于外壁，配合边缘、凸舌和凹槽保持光滑，隔间内部尺寸不变。STL 和 3MF 会包含浮雕，并保留各层独立的可打印零件。更换打印机或材料后，请先打印小样检查配合。

<a id="manage-filament-slots"></a>
### 管理耗材槽位

在 **打印** → **Slicer filaments** 中设置与切片软件一致的槽号和颜色。Snapmaker U1 的槽 1–4 对应打印头 T0–T3。最多可设置 16 个槽，每槽可指定颜色和材料名称。颜色仅供大致辨认，不模拟打印或混色效果；精确混色请在切片软件中设置。选择耗材卡片后，点击 **Delete filament from slot N** 删除该耗材。其他槽不重新编号：删除槽 6 后，槽 7 仍为 7。**+ Slot N** 会重新使用最小的空闲槽号，数量上限仍为 16。删除耗材不会改变模型颜色。已删除的槽不再供导出选择或自动匹配，请手动选择其他槽，或在切片软件中分配。不同颜色可自动匹配耗材；如果两个槽颜色相同，请在下载窗口为每个零件明确选择槽号。

如需与切片软件使用相同的数字颜色，请在颜色选择器旁输入六位 **HEX code**，例如 `#E63522`；开头的 `#` 可省略。有效代码会立即更新预览。未完成或无效的输入不会应用，离开输入框后会恢复已保存的颜色。相同代码并不模拟实际耗材外观、照明或物理混色。
