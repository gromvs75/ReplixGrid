<a id="start-a-new-project"></a>
## 开始新项目

首次启动时，工作区为空。左侧向导分为三个步骤：**选择形状 → 设置尺寸 → 添加隔间**。选择形状并设置尺寸后，点击**下一步：隔间**，最后选择**完成**或**不添加隔板**。选好形状后，也可以点击**×**关闭向导。您还可以打开已保存的项目或 JSON 文件。

**在小屏幕上：**当浏览器窗口宽度不超过 1400 px 时，助手会显示在**模型下方**，避免遮挡预览。请**向下滚动页面**，查看助手、后续步骤以及进入隔间设置和完成操作的按钮。向上滚动即可再次查看模型。在更宽的窗口中，助手仍位于左侧菜单旁。

通过**帮助 → 向导：三个步骤**可再次打开向导。打开向导不会改变模型；选择其他形状会替换当前模型，此操作可以撤销。

快速入门、用户指南和帮助菜单使用当前界面语言。视频仍为英语。

向导中的步骤、提示和保存确认均已翻译。已保存模型的条目显示为**上一个项目**。**我的项目**中的实际项目名称保持保存时的原样。

在顶部栏使用 **新建项目** 以返回此干净的启动。 您当前的工作是先保存的; 在 **我的项目**。 现有工程、 变体、 丝线槽和打印机配置没有被删除。 面板显示一个缩略图标签 **上一个项目** 与 **已保存到“我的项目”** ; 单击该行以重新打开您的库。 画布立即被清除, 并保持空置, 直到您选择了新形状, 就像第一次访问一样。 直到您选择了新形状, 保存和导出被禁用 。 您可以从 **我的项目** 或导入它的 JSON 文件打开一个工程。 刷新此空启动标签, 保留启动屏幕; 重新打开已有工程恢复了模型 。 普通返回访问恢复已保存的工作 。

选择 **形状 → 底部形状 → 从模板创建** 同时编辑仍然取代当前工程内部的构造, 并且可以被撤销。 如果您需要单独的模型, 请使用 **新建项目** 。

<a id="workspace-and-views"></a>
## 工作区与视图

在左上方打开一个工具 。 **形状** 改变车体及其附件 。 **分格** 改变布局 。 **外壳** 设计一个单独的外部封面 。 **打印** 设置了建筑体积、 丝状槽和可选的区块剪切 。 点击模型上的区块编号、 墙壁或分隔器打开右边的设置 。 如果一个部分难以点击, 请扩展 **所有墙壁和隔间** 并按名称选择它 。

在左侧菜单选择一个设置分类，其选项会在预览区底部的浮动面板中打开，模型和网格仍显示在面板后方。浮动面板不会替代左侧菜单。箭头用于折叠面板，**×** 用于关闭。选择其他分类即可切换设置；右侧面板始终用于当前选中的壁面或隔间。

拖动背景可旋转模型，滚轮可缩放，按住鼠标右键拖动可平移。**归还相机** 恢复默认取景。**俯视** 便于选择狭窄隔间和移动隔板；**三维** 显示壁高及组装效果。**网格** 显示间距 10 mm 的细线及间距 50 mm 的主线。模型上方的按钮可单独显示收纳盒、内衬、外壳或盖子；**组装视图** 显示当前可用零件。多层项目请打开 **收纳盒** 旁的下拉菜单：**查看堆栈** 显示整套堆叠模型，选择层号则返回该层编辑。底部编辑面板保持打开。堆叠视图中的 **外壳** 和 **内衬** 包含各层零件。窗口较窄时，这些按钮移到工具栏下方。单独查看盖子时，**底部** 显示其下侧。**Esc** 关闭工具面板；弯箭头用于撤销和重做。

使用顶端栏来选择介面语言或在光,暗和系统外观之间切换,本指南中的控制名称遵循所选界面语言.

<a id="shape-and-dimensions"></a>
## 形状与尺寸

在 **形状 → 底部形状** 下,选择一个底部和高度配置,然后从模板中单击 **从模板创建** 。该按钮将替换当前构造。 如果您想要保留两个设计, 请先保存一个命名的复制件 。 **基础模板** 也提供了一个空的正文和一个四部分的起点 。

| 基础 | 什么时候选? |
| --- | --- |
| 四舍五入 | 长方形足迹,外角可调整. |
| 顶盖 | 具有半圆形末端的长体,斜面模板通过两个弯曲的末端承载着线条. |
| 圆形 | 直径大小的圆形组织者. |
| 欧华 | 具有可单独调整宽度和深度的长曲线大纲。 |
| 蜂窝 | 一组共用墙壁的六边形单元格。选择一个单元格来调整其高度。 |

选择 **等高** 的等宽线圈, **斜坡** 的等宽线圈, 或者 **阶梯** 的等高线。 下方的等宽线框描述您将要创建的模板。 一旦创建, 请在 **尺寸** 下编辑模型 。 宽度和深度测量外部足迹 。 在对对象进行缩放时, 请使用选中的区块的内侧尺寸 。 在曲线基座上, 请检查 **俯视** 视图中的收缩端 。

![胶囊,低端供进入,高端供长项和两个横截面分隔器使用](../../images/capsule-sloped.jpg)

在 **形状** → **附加** 中设置壁厚和底厚。壁越厚，隔间可用空间越小。**在平坦的底座上倾斜** 将壁面向前倾斜最多 25°，底面仍保持水平；斜顶轮廓则是沿盒体改变壁高，两者不同。启用倾斜后，请在下载窗口检查零件的最终外部尺寸。

<a id="exact-internal-dimensions"></a>
## 精确设置内部尺寸

选择隔间后，在右侧打开 **内部尺寸**，或直接点击模型上的蓝色尺寸。选择宽度或深度并输入毫米值。点击输入框外或按 **Enter** 应用，**Escape** 取消；右侧面板使用 **应用** 按钮。无效值不会改变模型，每次确认的修改均可一步撤销。

橙色分隔器是它的当前位置; 虚线蓝线预览新位置。 所选择的轴线移动上最接近的分隔线, 保持外部体积和壁厚不变。 面板显示受影响的邻居大小。 如果该轴上没有分隔线, 请先调整总体尺寸或分割隔间 。

在简单的一行中,从1号隔间开始,然后按顺序继续;最后的隔间取其余部分. 邻里维度没有锁定,因此编辑早期的隔间可以调整后期的隔间大小.

精确尺寸编辑支持圆角、胶囊形、倒角和内部圆角。蓝线测量的是隔间中心线上、略高于底面的实际内部尺寸。弯曲处可能更窄，请留出间隙并检查物品的完整轮廓。圆形、椭圆形、蜂窝形和倾斜壁面暂不支持精确编辑隔间尺寸。

选择一个墙壁或分隔符直接在模型上编辑其高度。平面墙显示一个值;两点剖面图显示A/B值。链接高度和加速度墙规则匹配右面板。这些标签是编辑高度的,而不是壁长或全局厚度。

<a id="compartments-and-dividers"></a>
## 隔间与隔板

为了快速布局, 请使用 **分格 → + 隔间** 将最大的隔间拆开。 **- 隔间** 合并邻对 。 在蜂窝中,这些控制器会添加或移除一个外部细胞,并保留其他细胞的大小. 两个相邻的蜂窝细胞共用一堵墙,比高的细胞要高.

对于精确的布局,切换到 **俯视** 并选择要分割的分隔区块。 选择 **零件数量** ,则 **分割 沿宽度** 将宽度划分为更窄的隔间,或 **分割 沿深度** 用来做更浅的。 可以再分一个结果. 对于两个小托盘旁边的铅笔湾,首先将宽度分成两块,然后将托盘侧面分成深度.

![一个全深的海湾和两个较小的隔间](../../images/compartment-splits.svg)

选择分隔符以拖动它, 或调整 **第一隔间** 在 **隔断位置** 。 只有选定的分隔符移动; 其他分隔符位置仍然固定。 相邻分隔符改变大小, 空间太小的分隔符被拒绝 。 请检查每一边新的内侧尺寸 。 **删除分区** 将分隔符合并起来, 也可以删除嵌入该分隔符内的分隔符 。 在删除分隔符前审查突出显示的选中符和确认符 。

<a id="wall-heights-and-cutouts"></a>
## 壁高与缺口

选择外壁或隔板。**一个高度** 设置等高顶边；**两个点** 分别设置模型所示 A、B 两端的高度。**直接的**、**波浪形** 和 **之字形** 决定边缘轮廓，波长控制重复间距。阶梯模板中，修改某一级也会调整关联的壁面和隔板。

使用 **连接相邻墙的高度** 使外墙跟随邻居。 对于分隔者来说, **适合相邻的墙壁** 复制过两端的高度。 在改变相邻墙后重复一次 。 **和其他人一样** 将选定的墙返回到共同的高度 。

打开 **侧壁缺口** 以进行伸缩打开。 选择一个平滑的圆锥、 半圆圈或长方形的开口, 设置宽度和深度, 然后沿着墙壁移动 。 位置从 A 端到 B 端。 深度从顶端向下测量 。 请检查底面上方的余唇 。 选择 **无缺口** 来填充开口 。 Honeycomb 使用单元格高度 。 steped round 和 oval 不支持外墙的剪切 。

<a id="corners-edges-and-decoration"></a>
## 转角、边缘与装饰

打开 **形状 → 拐角和倒角**. 三个控件会影响打印的不同部分.

| 控件 | 向甚么处寻. | 改变的是什么 |
| --- | --- | --- |
| 外部角点 | 顶部视图, 外部大纲 | 环绕脚印角或砍在45°处,零度给出一个方角,可用在长方形的基座家族上. |
| 区间内的半径 | 顶部视图,在海湾内 | 绕过两面墙相交的垂直交叉点,紧湾限制了可用的半径. |
| 墙壁和分隔器的顶端 | 横穿墙壁 | **倒角**剪断扁平的贝子,**圆角**曲折的唇,两侧的外墙和分隔器都得到尾部. **无**还原了方唇. |

![墙体横截面显示正方形、色调和圆形上角,壁厚度相同](../../images/top-edge-profiles.svg)

例如,在2毫米的墙壁上尝试0.5毫米的夹层. 每一边在顶部都损失0.5毫米,留下一个1毫米的平面条纹,显示的最大尺寸取决于壁厚度. 有了**圆角**,值是半径,以毫米计.

- **收纳盒颜色** 更改预览和色能导出。选择一个监视、自定义的颜色或配置的丝状颜色。在导出时指定实际的丝状槽。
- **底部装饰边** 在基座上添加一个投影带。 选择平滑、 条纹或脚步裁剪并设定高度。 兼容的袖子可以停留在基座上。 Trim需要一个已整齐的单件体, 并且可以放在第一层上。 单独的面板坐在基座上方, 并带有选定的边缘偏移 。
- **收纳盒浮雕** 在外墙上直接添加了提升的图案。 滚动图案目录, 设定图案大小和减速高度, 并在每次计算完成时在拖曳时观看模型更新。 最终值使用完全精确度。 内部保持平滑。 预测会增加外墙的尺寸 。 选择 **光滑的** 来删除减速值 。
- **文字与图标** 将字母或符号放在选定的一侧。 请输入文字, 选择字体, 设定字母高度和垂直位置, 然后选择升起的字母或雕刻, 并设定其高度或深度。 恒星或心脏可以伴随文字。 在圆形和椭圆形组织者上, 文本和图标沿着曲线壁, 包括STL 和 3MF 导出。 字母间隔沿表面测量。 请选择 Front, Rear, 左侧或右侧, 将铭文居于该侧。 在有链接或不同壁高的圆形和椭圆形上, 将字母保留在壁下方和剪切度以下 。 蜂蜜组合字母尚未支持; 覆盖选定侧面和解弹也可以防止字母。 Flat- wall 字母仍然需要一个恒高的配置 。 如果文字被切入或超过可用面, 请降低位置或缩小字母大小 。

<a id="inserts-tiers-and-lids"></a>
## 内盒、层数与盖子

**可拆卸内衬。**选择隔间后，在右侧打开 **分格内衬**。**空** 创建开放容器；**对于小事** 创建行列数可调的分格；**用于手柄** 创建笔或工具插孔。设置插孔内径后，应用会尽量排入可容纳的数量。可选择贴合隔间、圆角、圆形、椭圆形或六边形轮廓及颜色。**移除插入件** 删除内衬。空内衬也是独立的可打印零件。

该插件沿着其隔间至少0.5毫米清除。 它的墙壁和底部厚度为1.2毫米,其高度则调整到边缘下方约1毫米完成. 倾斜的收纳盒中的插件沿着斜坡伸出。 隔离 **内衬** 检查它们,然后导出 **整理器和配件** . 插入需要单件打印。

**堆叠的托盘。** 开始为关卡环形,然后打开 **形状 → 层数 → + 等级** . 可使用2至5级; **- 层** 删除一层。 梯级共用一个足迹,但可以有不同的隔间,高度,颜色和装饰.

1. 在模式上的 **收纳盒** 旁边的下拉中,选择 **第 1 层**, **第 2 层** 或另一级。该级是单独显示的,当前设置编辑器仍然打开 。
2. 以通常的形状、 隔间、 解析和 shell 控件编辑选中的级。 更改级不会将其设置复制到其他级 。
3. 在同一下拉处选择 **查看堆栈** 来检查所有级别和附件。 使用 **组装视图**, **收纳盒**, **内衬**, **外壳** 或 **盖子** 来显示您需要的部件。 返回到一个编号级别继续编辑它 。
4. 在 **形状** → **层数** 中设置 **配合间隙**，先用小样检查配合，再打印整套。请降低高于顶边的隔板。堆叠要求壁面竖直且支撑边缘连续。

内置和 SVG 解析器在交配的领、舌和套接字保持平滑的同时装饰每层的外表。包装的外壳和装饰面板可以覆盖各层。对于面板,请保留**边缘偏移** 至少3毫米,以便清除交配面圈。

使用整圈外壳时，下层壁面内侧的凸舌插入上层底部下方的槽。隔间可用宽度、深度和高度不变；每个槽会使堆叠后的外部高度增加 2.2 mm。外壳之间通过宽 0.8 mm 的支撑带接触。外壳从上方套入，因此拆下前需先分开各层。每个外壳单独导出，并标有层号。

**底部装饰边** 仅存在于第一层( 最低) : 选择平滑、 环或步骤 。 使用兼容的包壳, 修饰也支持外壳 。 单独的面板坐落在修饰上方, 选择的边缘被抵消 。 新的上层不会继承修饰 。 如果凸舌不能适应壁厚度, 请减少 **配合间隙** ; 应用程序不会自动加厚墙 。 隔墙必须留下足够的材料, 以支撑上面的托盘 。

**盖子。**打开 **形状** → **盖子**，点击 **+ 封面**。外壁顶边必须等高，隔板不得高于顶边。倾斜、蜂窝形和分段打印不支持盖子。**外盖式** 从外部盖合；**内嵌式** 是厚 2 mm、与顶边齐平的内嵌板。内嵌盖的安装台阶每侧留 0.35 mm 间隙，并在隔板和内衬上方留出空间；要求壁厚至少 2 mm、内部深度至少 4 mm。可添加缺口或把手方便取下。外盖的定位边留有 0.5 mm 间隙。设置图案、尺寸、深度、边缘高度及倒角或圆角。把手可为圆柱形或长条形，尺寸、高度和边缘处理可调；需单独打印后粘接。预览中外盖被抬起，内嵌盖位于安装位置。导出时盖子会平放以便打印。

**双色图案** 适用于两种盖子。可选择橄榄枝、银杏叶、蕨叶、波浪、河卵石、年轮或 Voronoi 单元，并设置底色和图案色。3.2 mm 厚的板由 1.6 mm 实心底层和 1.6 mm 图案层组成；外盖定位边及把手会增加总高度。内嵌盖要求内部深度至少 5.2 mm。导出 3MF 可保持两个彩色部分的相对位置，再为各部分分配耗材。橄榄枝、银杏叶、蕨叶、波浪和年轮的 **镂空图案** 会在上层形成开口。启用 **浮雕图案** 后，深 1.6 mm 的开口保持空置，露出下方底层；关闭后则形成平整的镶嵌效果。内嵌浮雕盖应底层朝下打印，外盖应图案面朝下打印。请在切片软件中检查凹处上方的桥接。

| **装饰板** | 单独的边框覆盖选定的边框并让角暴露。 选择边框并调整 **边缘偏移**。 粘贴面板不绑紧。 用隐藏的针头, 按每面板直排在匹配的墙上, 以便永久附加 。 |

<a id="projects-and-backups"></a>
## 项目与备份

使用 **我的项目 → 保存副本** 在实验前命名一个设计或制作一个变体。 打开的工程会自动保存在这个浏览器中。 库允许您搜索、 打开、 重命名、 删除或下载一个工程 。 **保存项目** 在顶部的栏下下载一个可编辑的 JSON 备份 。 使用 **打开** 来加载该文件, 包括放在另一台计算机或本地安装中 。

强制编辑被立即保存。 当浏览器数据库保存时, 临时本地恢复副本保护更改; 如果写入中断, 重新恢复副本。 单独的最后一个成功快照可以恢复损坏的当前会话, 包括取消历史。 如果无法恢复有效副本, 自动保存停止, 而不是以启动模式取代存储的项目。 保留可下载的 JSON 备份: 浏览器数据清理或两种存储机制的失败无法自动恢复 。

导出检查属于当前工程修改、 选定部件和挂起位置。 更改这些修改会使上一个检查无效; 旧结果不能作为新模型下载。 失败的计算会保留编辑。 预览在两分钟后报告出错; 下一次几何编辑会开始新的计算 。

当同一个工程或抽屉被编辑到多个标签中时, 相互冲突的更改会被保存为单独的 **Copy from another tab** 。 另一个版本被保存, 编辑标签继续复制。 比较 **我的项目** 或抽屉选择器中的版本, 并重命名副本, 如果您想要保存的话。 重新打开一个组织者标签会恢复它自己保存的工程。 更改不会在标签中自动合并 。

在清除浏览器数据之前保留一个已下载的备份。 每个浏览器和站点地址都有自己的库。 Filament 插槽会单独存储在浏览器中的打印机。 在移动到另一个设备时再次设置它们。 关于可下载的本地应用程序, 请参见 [本地安装](../../../README.md#local-installation)。

<a id="print-setup-and-sectioning"></a>
## 打印设置与分段

在 **打印** 下,选择您的打印机和头部配置或选择 **自定义尺寸**。请检查模型计算宽度、深度和高度。预设会提供模型计算的音量。请在切片软件中选择打印机、喷嘴、材料和切片配置。

模型超出打印平台时，可使用建议的分割位置，或在可用时选择分成两段或三段。用 **将部件分开** 检查接合处。分割会将壁厚增至至少 5 mm、底厚增至至少 3 mm，因此需要重新检查内部尺寸。分割前请移除外壳和内衬。多层、倾斜、圆形、椭圆形和蜂窝形模型必须整体打印。**返回实体模型** 可取消分割；如需恢复原有尺寸，请重新检查厚度。

**↓ Joint sample**可下载接合部位的测试模型。使用与最终模型相同的缩放比例和打印设置，将样件分开放置，底面朝下打印。冷却后，标称直径 3.2×8 mm 的定位销插入直径 3.3 mm 的孔中；接缝两侧的孔深均为 4.5 mm。检查对齐后，用定位销和胶水组装打印好的分块。组织盒本体请使用**↓ 下载所有部分**。

<a id="download-and-slice"></a>
## 下载并在切片软件中准备

1. 在 **打印** → **Slicer filaments** 中设置与切片软件一致的槽号和颜色。Snapmaker U1 的槽 1–4 对应打印头 T0–T3。最多可设置 16 个槽，每槽可指定颜色和材料名称。颜色仅供大致辨认，不模拟打印或混色效果；精确混色请在切片软件中设置。选择耗材卡片后，点击 **Delete filament from slot N** 删除该耗材。其他槽不重新编号：删除槽 6 后，槽 7 仍为 7。**+ Slot N** 会重新使用最小的空闲槽号，数量上限仍为 16。删除耗材不会改变模型颜色。已删除的槽不再供导出选择或自动匹配，请手动选择其他槽，或在切片软件中分配。不同颜色可自动匹配耗材；如果两个槽颜色相同，请在下载窗口为每个零件明确选择槽号。
2. 单击 **↓ 下载** . 选择 **整理器和配件** , **仅外壳** 或 时 间 **整套** ,根据您需要的部件。 对于一个分门别类的模型,导出工具包.
3. 在下面选择一个格式。 对于 3MF, 给每个部分指定一个丝状槽, 或者把它留在切片软件中指定。 Orca 可以使用第一个丝状槽来进行未指定的部件 。
4. 等待几何和大小检查。 读取每个部分的尺寸和任何在打印平台上旋转90°的指示。 检查在平台边缘保留了2毫米。 下载时要使用对话框底部的格式按钮 。
5. 在切片软件中打开导出文件，使用**毫米单位和 100% 缩放比例**。排列所有零件，检查悬垂和细小结构，并预览首层及隔板。多色打印前，请确认每个零件的耗材分配。

| 格式 | 选择它 | 下载怎么办? |
| --- | --- | --- |
| STL 编 | 单色打印的几何 | 在切片软件中打开 STL。 如果导出包含多个 STL , 请先提取 ZIP 。 |
| 3MF | 具有不同部件、颜色和丝线任务的工具包 | 在切片软件中打开并验证部件和插槽。 ReplixGrid 将打印机和材料配置文件留给切片软件 。 |
| OBJ + MTL | 接受 OBJ 工具的彩色模型 | 将几何学和材料文件保存在一起,模型使用Z上方的毫米. |
| JSON项目 | 继续编辑隔间、尺寸或附件 | 使用**保存项目**并在ReplixGrid中与**打开**重开. |


如需与切片软件使用相同的数字颜色，请在颜色选择器旁输入六位 **HEX code**，例如 `#E63522`；开头的 `#` 可省略。有效代码会立即更新预览。未完成或无效的输入不会应用，离开输入框后会恢复已保存的颜色。相同代码并不模拟实际耗材外观、照明或物理混色。

## 故障排除

| 你看见的 | 检查什么? |
| --- | --- |
| 物体符合外部尺寸,但不会在海湾中 | 选择隔间并检查其内部测量. 允许壁厚,曲线端,角半径内和可移动插入. |
| 选择分隔符继续选择前面的壁 | 切换到**俯视**或打开**所有墙壁和隔间**. |
| 无法添加盖或下一层 | 检查一个平面轮廓, 等值的外部高度, 铺设分隔器, 倾斜或分割打印。 对于一个堆栈, 还检查遗留的外壳夹, 以及相对于壁厚度的适切清除 。 内建和 SVG 浮雕被支持在单个平面上; 交配表面保持平滑 。 |
| 虽然脚印足够小,但有部分超过了打印平台 | 在下载对话框中读取完成的维度。 倾斜、 浮雕、 修剪和外壳可以延伸至底部以外。 请检查所选的打印机配置和旋转 。 |

| 下载的打印有错误的颜色 | 使用 3MF,匹配**打印**中的槽号,然后检查切片软件中的每段任务. STL只携带几何. |
| 缺少保存在另一个设备上的设计 | 将其项目JSON并使用**打开**. 浏览器库是本地到每个设备和站点地址的. |

## 项目版本

单击 **+ 变体** 在顶端栏,或打开 **我的项目** 选择 **新建变体** . 输入名称并单击 **创建变体** . 新变体为独立副本;原存保存. 未命名原件保留为 **草稿** .

在旁边使用选择器 **+ 变体** 在相关模型之间切换,或选择一个 **此项目的变体** 在我的项目。 每个变体在切换或重新加载后自动保存并保留自己的撤销/重做历史. 一个新创建的变体从空历史开始.

使用 **独立项目 → 保存副本** 创建一个无关的工程。 在 My 工程中重命名或删除单个模型; 删除原件不会删除其变体 。

**↓ 下载** 输出选中的打印模式 。 **保存项目** 下载该模式为可编辑 JSON; **文件** 在一个库卡上下载相应的模式 。 JSON 包含一个模式,没有与之相关的变体或取消历史 。 将每个模式单独保存以传输或备份完整的组合 。


<a id="shared-styles"></a>
## 共享样式

1. 打开一个带有您想要重复使用的颜色和图案的工程 。
2. 在 **形状 → 通用样式** 下,输入名称并点击 **保存当前样式**.
3. 打开另一个工程或变体,返回 **通用样式**,并选择保存的样式。
4. 选择 **颜色**, **图案**, 或两者兼有。 审查 **将应用** 和任何 **将跳过** 信件, 然后点击 **应用样式** 。

样式可以捕捉收纳盒的颜色和浮雕, 加上现有 shell 和 盖子的颜色和图案。 平滑的车身样式可以消除目的地的身体浮雕。 尺寸、 隔间布局、 壁厚度、 盖盖、 柄和 shell 清除不变 。 缺少的盖子或外壳没有添加 。 用解释跳过不兼容的样式设置; 兼容的设置仍然可以应用 。 插入颜色和丝带槽任务不会转移 。

应用程序是一个撤消步骤, 并创建一个独立的复制件: 以后编辑到一个组织者不会更改其他的。 删除一个保存的样式不会改变已经使用它的项目 。

保存的样式属于此浏览器和站点地址. 一个JSON项目保留了应用的外观,但不包括保存的样式库. 要在另一个设备上重用样式,请在那里打开该样式的项目的JSON,并再次保存其当前样式.


<a id="drawer-arrangements"></a>
## 抽屉内的收纳盒布局

在 **Drawer** 旁选择 **收纳盒** , 然后选择 **Create drawer** 。 输入所测量的内宽度、 宽度、 可用高度和清除度 。 清除既适用于抽屉的墙壁, 也适用于托盘之间 。

新的抽屉从180×280毫米开始,前缘标注在底部. **旋转视图 90 度** 只更改查看方向;抽屉尺寸、托盘坐标和导出模型保持不变。 现有的抽屉安排保留其尺寸。 保存的抽屉以长度水平和宽度垂直打开;尺寸标签遵循手动视图旋转. 托盘旋转按钮只转动选中的托盘 。

使用 **New organizer** 直接在抽屉中创建托盘。 设置其尺寸, 然后在通常的收纳盒编辑器中编辑隔间和附件 。 **← Back to drawer** 返回其位置 。 **Add saved organizer** 添加了保存的工程或变体的独立副本; 编辑它永远不会改变其来源 。

在顶部视图中拖动托盘或输入从左上角测量到托盘外部边框的X/Y坐标。旋转90度,复制或删除托盘。箭头键将焦点托盘移动1毫米(Shift: 10毫米) 。 安排撤消/重置恢复放置和完成托盘编辑 。

图表显示组装的外部边框矩形, 包括外壳、 剪切、 盖子和阶梯。 弯曲的形状被保守地检查, 而不是紧密地嵌入。 边界、 清除和高度冲突被突出显示。 等待几何检查后, 才能依赖合适的状态 。 选择自由放置或启用下面描述的嵌入板 。

绘制器从本地保存到此浏览器, 独立于收纳盒项目。 下载一个抽屉 JSON 文件进行备份或传输; 打开一个文件会创建单独的抽屉副本。 选择一个托盘并选择 **Download selected tray** 用于它自己的 STL, 3MF 或 OBJ 导出, 并使用现有的打印机大小检查。 绘制器坐标不会成为打印打印平台位置 。

<a id="mounting-plates"></a>
### 安装底板

在 **Drawer → Drawer base** 中选择 **Mounting plate**。抽屉的长宽和侧壁间隙决定覆盖面积。分别输入 **3D 打印机热床**的可用宽度和深度；这些尺寸决定单块板的最大尺寸和分块数量。计算包含连接结构的突出部分，并在热床每侧预留 2 mm 打印余量。尺寸无需是 20 mm 定位网格的整数倍；边缘分块会适配剩余空间。

**Download sections (ZIP)** 为每次打印生成带编号的 3MF、SVG 组装图及坐标表。图中始终使用抽屉原始方向，不随视图旋转：R 表示从上到下的行，C 表示从左到右的列。燕尾接头从上方插入。请先打印 **Download joint sample** 中的两块相邻小样，确认配合后再打印全套。接缝间隙为 0.05 mm，轮廓余量为 0.03 mm。尚未安装收纳盒时，板块之间可能有细缝和轻微松动。

启用板块模式后, 托盘下载包括该托盘位置和旋转的下侧套座。 内部隔间尺寸被保留。 托盘高2.1 毫米; 包括2 毫米板块, 抽屉适配检查会增加4.1 毫米。 在移动或旋转托盘后, 重新下载: 其套座必须匹配套座位置 。 更改抽屉清除也会改变连接源 。

袜子射线清除为0.12毫米. 打印一个横跨两节的小收纳盒,以检查是否适合您的材料和图层设置 。 套接字会横向保留组织者; 向上提升以删除它 。 导出只使用几何:在切片软件中选择您的打印机和材料配置,并在打印前检查套接字顶部 。

安装固定目前支持未分割、未倾斜的收纳盒，且至少要有三个完全受支撑的安装孔。小收纳盒可能需要移动或放大。上层和外壳保持原有几何形状。关闭底板模式即可导出原始的无固定孔模型；已保存的源项目不会改变。

<a id="custom-svg-relief"></a>
## 自定义 SVG 浮雕

在 **形状 → 收纳盒浮雕 → My SVGs**, 选择 **Upload SVG** 或将一个文件降入上传区域 。 选择一个保存的缩略图来重用它 。 在 **形状 → 盖子 → My SVGs** 和 **外壳 → Pattern → My SVGs** 下 , 同一库可供使用 。 每个目标都保持自己的模式和位置设置 。

选择 **Single motif** 或 **Repeat**, 选择外墙, 并按毫米、 旋转、 水平/ 垂直抵消和重复差距调整外墙宽度 。 宽度和高度保持原比例 。 放置在每一个选定的侧面上; 侧面对应于四个外侧区域 。 垂直偏移正向上。 模式遵循外侧轮廓 。 重复只放在完全的侧面下方、 四周和两侧之间 。 在这些边界上剪剪切 。 使用现有的 **救援深度/强度** 控制 。 保留原有的壁和内侧面。 外部尺寸增加 。 等待更新预览完成后, 然后检查和下载该部分 。

支持的 SVG 包含填充路径、多边形、矩形、圆形或椭圆, 包括孔和组变换。 在从向量编辑器导出之前, 将文本和中键转换为填充路径 。 照片、 外部引用、 过滤器、 口罩、 剪切路径、 渐变、 CSS 样式块和可重复使用元素的引用( `use`) 不支持 。 忽略包含支持形状的空定义或未使用的定义 。 颜色会使用收纳盒的颜色成为单一的升起形状 。 限制是 200 KB、 512 XML 元素、 128 填充形状和 6 000 个样复发点; 使用信件拒绝过于复杂的模式或过多的重复 。 用于打印的缩略图。

SVG 在浏览器中本地处理。 库会保留在这个设备上。 每个工程都会嵌入一个其已使用轮廓的独立拷贝, 所以下载的项目可以在另一个设备上重新打开, 而不用源 SVG 或库。 删除一个库条目会保留已有的项目不变 。 **通用样式** 还会将自定义的正文、 盖子和 shell 模式带给另一个组织者 。 缺少的盖子或外壳会被跳过, 就像内置样式一样。 保留一个下载的项目作为备份 。

<a id="choose-an-svg-for-its-intended-use"></a>
### 根据用途选择 SVG

SVG是一种绘图格式,而不是可打印几何的保证. **导入成功仅意味着所支持的填充大纲被读取 。** 选择的表面,大小和应用模式仍然需要通过几何检查.

| 预定用途 | 填满的区域变成什么 | 准备什么 |
| --- | --- | --- |
| 组织者浮雕 | 固壁上附着的升起材料 | 分开的齿轮和内孔可以起作用,因为墙壁支撑着它们. |
| 升起的盖状图案 | 坚固支持的材料 | 内孔是允许的;将整幅图画保存在可用框架内,并清除手柄落地. |
| 通过开口连接 | 从盖子上移走的材料 | 每个剩余部分必须连接到周围的盖子,封闭的内饰需要刻度桥. |
| 包装的外壳或装饰面板 | 打开封面 | 使用与速率兼容的绘图。 剩余框架和图案必须形成连接的材料 。 |

要准备文件 :

1. 保留所需的填充路径和基本形状。在矢量编辑器中将文字和**描边转换为填充轮廓**。带有 `fill="none"` 的可见线条是描边，不是填充区域。
2. 删除背景矩形，除非希望整个矩形都成为浮雕或通孔。SVG 颜色不会区分材料，白色形状也不会自动从下方深色形状中扣除。
3. 检查复合路径。写着“孔”的注释不会产生孔；内部是否填充取决于路径方向和 `fill-rule`。
4. 制作通孔时，用连接桥将封闭的内部细节连接到周围材料。增大重复间距**不能**固定图案内部的独立细节。也可改用盖子浮雕。
5. 重复模式建议使用只含一个图案的文件。如果 SVG 已含图案阵列，宽度会缩放**整个阵列**，而非每个图案单独缩放。细节可能因此变得过薄。
6. 等模型计算和导出检查通过后，再到切片软件中检查。计算失败时可能保留上一次成功的模型；它并不代表当前失败的设置。

实心叶片轮廓既可做浮雕，也可做叶形通孔。完全包围在叶片内的叶脉在浮雕模式下由底面支撑，但切穿周围叶片后可能成为脱落的独立部分。六边形网格可用于穿孔，前提是剩余连接桥相互连通且足够厚。由描边组成的多色插画需要先转换为填充轮廓。

<a id="svg-lids-and-perforated-shells"></a>
### SVG 盖子与镂空外壳

添加盖子后，选择 **My SVGs**。**Raised relief (decoration)**模式在实心底板上生成图案，形成一体式盖子；可设置浮雕高度（0.2–1 mm）和底色。**Through stencil (cut)**模式将 SVG 的填充区域贯穿切除。两种模式均保留 2 mm 边框和配合边缘。独立把手下方保留实心支撑区；如果单个图案与把手冲突，请移动图案。外盖和嵌入式盖子使用相同的控制项。SVG 中的颜色不会导入为独立耗材。

对于外壳,请选择 **My SVGs** ,然后是图书画。 填充区域通过开口而变为填充区域. 在一个包裹袖子的选定侧面使用一个摩提夫或重复。 打开 **装饰板** ,每个选定的面板上独立重复绘制图;保留现有的框架和挂载位置。 初始的motif大小会考虑外壳高度. 根据需要调整框架宽度、移动大小、旋转、位置和间隔。 组织者内部隔间及外壳清空情况不变.

在盖子和外壳上, 仅将完整的齿轮放置在可用框内, 包括单个齿轮。 如果无任何齿轮适合, 缩小大小或抵消。 闭合的内饰细节( 例如环形剪切的中心) 可以变成松散的岛屿 。 在您的矢量编辑器中添加桥, 或者在盖子上使用提升的装饰 。 应用程序会断开几何, 而不是静静地丢弃棋子 。 避免非常狭窄的网, 并检查您的材料和喷嘴的小型测试指纹 。

模式包含在单个部分的导出, 完整套件和全画幅打印任务中。 切换到 **Built-in** 只会从目标中删除自定义模式 。 删除一个库缩略图不会从项目中删除嵌入模式 。

### 下载可直接使用的 SVG 镂空模板

这些示例包含填充轮廓和连接桥。黑色区域在 **Through stencil (cut)** 模式下会成为通孔。请通过下方链接将文件保存为 `.svg`。如果浏览器直接显示图案，请使用保存页面功能，并保留 `.svg` 扩展名。

| 下载 | 图案 | 建议的起始宽度 |
| --- | --- | --- |
| [有机叶片——下载SVG](https://raw.githubusercontent.com/gromvs75/ReplixGrid/refs/heads/main/docs/examples/organic_leaf_pattern-stencil.svg) | 5片叶子 连接内部细节的桥梁 | 20毫米;低空壳减少 |
| [双六边形 — 下载 SVG](https://raw.githubusercontent.com/gromvs75/ReplixGrid/refs/heads/main/docs/examples/3d_print_pattern-stencil.svg) | 一个双六边形砖瓦,有四座桥和一个中央开口 | 20-24毫米;使用**Repeat**作为网格 |

**盖上:** 在 **形状 → 盖子** 下添加一个盖子, 打开 **My SVGs** 并上传文件。 选择 **Through stencil (cut)**。 用 **Single motif** 开始检查它, 或者选择 **Repeat** 以完整的副本填充可用的区域 。 设置宽度、 旋转和 X/ Y 抵消。 重复间隔是完整副本之间的间隔, 而不是其内部桥梁的宽度 。 以 4 mm 间隔开始 。 叶片文件已经是一个五叶组: 宽度缩放整个组 。

<a id="numeric-sliders-and-valid-ranges"></a>
### 数值滑块与有效范围

数字设置显示**Min**和**Max**在一个薄绿色轨道上方,对当前值有一个白色标记。红色端盖标记所允许间隔的外部;它们不是打印强度的评级。拖动标记,在聚焦时使用箭头键,或输入精确数字并按下 Enter。数字字段和滑动器使用相同的限制。有些限制会随着模型的变化而改变;滑动器范围内的值仍然可以与另一个设置相冲突,因此在导出前遵循任何几何警告。

<a id="whole-drawer-export"></a>
## 导出整个抽屉

选择 **Drawer → Print entire drawer** 以准备所有托盘、其附件和任何启用的挂载板块。 挂载托盘会接收保存位置的套座; 普通的自由置放托盘会保留其现有的基座。 拆分打印项目包括部件和针头。 重叠、 抽屉检查不足、 不支持挂载或无效的几何设置屏蔽下载并识别受影响的托盘 。

设置 **Printer bed length**( 横向) , **Printer bed width**( 垂直) , 打印高度和间距 。 初始维度来自挂盘设置或第一个托盘的打印区域; 随后的导出设置会用这个抽屉保存 。 挂盘部分会被重新生成到选中的打印平台。 这不会移动托盘或修改保存的源工程 。

排版使用导出零件的实际外部尺寸，并保留平台边缘 2 mm 余量及所选零件间距。零件可旋转 90°，多色盖子的各组成部分保持在一起。显示的平台数量仅适用于当前排版，不保证最少。支撑、裙边（brim）、擦料塔、打印机禁用区域及不同材料的独立打印任务不计入排版；请预留空间并在切片软件中检查。导出文件不包含打印机配置或耗材槽分配。

ZIP 中包含每个打印平台对应的 **bed-NN.3mf**、配套的 **bed-NN.svg** 示意图、**assembly.svg**、**print-plan.json**、**drawer.replixdrawer.json**，以及 **README.txt** 中的编号零件清单。将每个 3MF 文件作为独立打印任务打开，保留各对象的相对位置，使用毫米单位和 100% 缩放，并分配耗材。SVG 示意图显示包围矩形；3MF 包含完整可打印几何模型。抽屉组装坐标始终以长度为横向、宽度为纵向。

对布局或导出设置的更改使先前的计算无效。 关闭窗口会取消准备。 超大小的单个部件会被报告, 而不是默默缩放或自动拆分。 可能需要以较小的组数导出非常大的套数 。

<a id="pattern-studio"></a>
### 图案工作室

选择 **Raised relief (decoration)** 制作浮雕，或 **Through stencil (cut)** 制作通孔。外壳仅支持通孔。浮雕高度仅在浮雕模式显示，间距仅在重复模式显示。**Material thickness** 同时改变预览和导出：SVG 盖子为 1.2–6 mm，外壳为 1–4 mm。默认厚度为浮雕 3.2 mm、模板 2 mm；手动设置的厚度在切换模式后保留。浮雕高度已计入盖子厚度。内嵌 SVG 盖子要求内部深度至少为板厚加 2 mm。**附加** 提供盖子颜色或外壳壁面选择，**Which SVG files work?** 说明文件要求及准备方法。

打开 **形状** → **盖子** → **My SVGs** 或 **外壳** → **Pattern** → **My SVGs**。**盖子** 和 **外壳** 选项卡共用图案库，但设置互相独立。切换选项卡会单独显示相应零件；尚未添加该零件时，仍显示组装模型。也可在模型上方手动选择组装视图。宽度、旋转、间距和 X/Y 控制图案放置；居中按钮重置位置和旋转。盖子支持浮雕及通孔，外壳只支持通孔；边框和安装区域会保留。在工作室获得焦点时，按 **×** 或 **Escape** 关闭，修改仍会保存。方向键可切换已聚焦的选项卡。
