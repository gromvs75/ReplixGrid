<a id="start-a-new-project"></a>
## 开始新项目

首次启动时，工作区为空。左侧向导分为三个步骤：**选择形状 → 设置尺寸 → 添加隔间**。选择形状并设置尺寸后，点击**下一步：隔间**，最后选择**完成**或**不添加隔板**。选好形状后，也可以点击**×**关闭向导。您还可以打开已保存的项目或 JSON 文件。

通过**帮助 → 向导：三个步骤**可再次打开向导。打开向导不会改变模型；选择其他形状会替换当前模型，此操作可以撤销。

快速入门、用户指南和帮助菜单使用当前界面语言。视频仍为英语。

向导中的步骤、提示和保存确认均已翻译。已保存模型的条目显示为**上一个项目**。**我的项目**中的实际项目名称保持保存时的原样。

在顶部栏使用 **新建项目** 以返回此干净的启动。 您当前的工作是先保存的; 在 **我的项目**。 现有工程、 变体、 丝线槽和打印机配置没有被删除。 面板显示一个缩略图标签 **上一个项目** 与 **已保存到“我的项目”** ; 单击该行以重新打开您的库。 画布立即被清除, 并保持空置, 直到您选择了新形状, 就像第一次访问一样。 直到您选择了新形状, 保存和导出被禁用 。 您可以从 **我的项目** 或导入它的 JSON 文件打开一个工程。 刷新此空启动标签, 保留启动屏幕; 重新打开已有工程恢复了模型 。 普通返回访问恢复已保存的工作 。

选择 **形状 → 底部形状 → 从模板创建** 同时编辑仍然取代当前工程内部的构造, 并且可以被撤销。 如果您需要单独的模型, 请使用 **新建项目** 。

<a id="workspace-and-views"></a>
## 工作区与视图

在左上方打开一个工具 。 **形状** 改变车体及其附件 。 **分格** 改变布局 。 **外壳** 设计一个单独的外部封面 。 **打印** 设置了建筑体积、 丝状槽和可选的区块剪切 。 点击模型上的区块编号、 墙壁或分隔器打开右边的设置 。 如果一个部分难以点击, 请扩展 **所有墙壁和隔间** 并按名称选择它 。

左面板为段导航. 选择一个区域,仅在预览底部的中央浮动编辑器中打开其设置。 场景和网格在编辑器后面继续;打开不会切断预览. 编辑器使用紧凑组;它不会替换左侧菜单. 它的chevron崩溃了编辑和 **×** 关闭它。 选择左侧的另一节来切换设置 。 右面板仍专用于选定的墙壁或隔间.

拖动背景可旋转视角，滚轮可缩放，按住鼠标右键拖动可平移。**重置视角**恢复默认取景。**俯视**便于选择狭窄隔间和移动隔板；**3D**显示壁高及组装效果。**网格**显示参考线，细线间距为 10 mm，主线间距为 50 mm。模型上方的零件按钮可单独显示收纳盒、内衬、外壳或盖子。**组装视图**显示当前视图中的所有可用零件。多层项目可在**收纳盒**下拉菜单中选择**查看堆栈**来显示全部层，或选择**第 1 层**、**第 2 层**等返回单层视图；底部编辑面板保持打开。堆叠视图中的**外壳**和**内衬**包含各层对应的零件。窗口较窄时，这些按钮移至工具栏下方。单独查看盖子时，可选择**底面**检查盖子下侧。按 **Esc** 关闭工具面板。模型上方的弯箭头用于撤销和重做。

使用顶端栏来选择介面语言或在光,暗和系统外观之间切换,本指南中的控制名称遵循所选界面语言.

<a id="shape-and-dimensions"></a>
## 形状与尺寸

在 **形状 → 底部形状** 下,选择一个底部和高度配置,然后从模板中单击 **从模板创建** 。该按钮将替换当前构造。 如果您想要保留两个设计, 请先保存一个命名的复制件 。 **基础模板** 也提供了一个空的正文和一个四部分的起点 。

| 基础 | 什么时候选? |
| --- | --- |
| 四舍五入 | 长方形足迹,外角可调整. |
| 顶盖 | 具有半圆形末端的长体,斜面模板通过两个弯曲的末端承载着线条. |
| 圆形 | 直径大小的圆形组织者. |
| 欧华 | 具有可单独调整宽度和深度的长曲线大纲。 |
| 蜂窝 | 一组共用墙壁的六边形单元格。选择一个单元格来调整其高度。 |

选择 **Flat** 的等宽线圈, **斜坡** 的等宽线圈, 或者 **阶梯** 的等高线。 下方的等宽线框描述您将要创建的模板。 一旦创建, 请在 **尺寸** 下编辑模型 。 宽度和深度测量外部足迹 。 在对对象进行缩放时, 请使用选中的区块的内侧尺寸 。 在曲线基座上, 请检查 **俯视** 视图中的收缩端 。

![胶囊,低端供进入,高端供长项和两个横截面分隔器使用](../../images/capsule-sloped.jpg)

**形状 → 附加** 包含壁厚和底厚。 钩子墙从隔间中取出空间. **在平坦的底座上倾斜** 将壁向前倾斜至25°,而底部则保持水平. 这与坡度的环形不同,这改变了沿身体的壁高. 启用倾斜时, 请使用下载对话框中完成的尺寸来检查打印部分将占用的空间 。

<a id="exact-internal-dimensions"></a>
## 精确设置内部尺寸

在右面板中选择一个区块并使用 **内部尺寸**, 或直接单击模型上的蓝色维度标签。 选择宽度或深度, 输入毫米并单击内线字段外应用。 请输入; 取消。 右面板保留其应用按钮。 无效的值不能改变模型。 每个承诺的编辑可以一步取消 。

橙色分隔器是它的当前位置; 虚线蓝线预览新位置。 所选择的轴线移动上最接近的分隔线, 保持外部体积和壁厚不变。 面板显示受影响的邻居大小。 如果该轴上没有分隔线, 请先调整总体尺寸或分割隔间 。

在简单的一行中,从1号隔间开始,然后按顺序继续;最后的隔间取其余部分. 邻里维度没有锁定,因此编辑早期的隔间可以调整后期的隔间大小.

圆角、 胶囊轮廓、 底盘和内填片仍然得到支持。 蓝线测量隔间中心线的实际内部跨度, 就在地板上方。 空间可以围绕曲线在其他地方缩小: 添加清除和检查整个物体足迹 。 圆形、 椭圆形、 蜂窝形和斜壁目前不支持精确的隔间编辑 。

选择一个墙壁或分隔符直接在模型上编辑其高度。平面墙显示一个值;两点剖面图显示A/B值。链接高度和加速度墙规则匹配右面板。这些标签是编辑高度的,而不是壁长或全局厚度。

<a id="compartments-and-dividers"></a>
## 隔间与隔板

为了快速布局, 请使用 **分格 → + 隔间** 将最大的隔间拆开。 **- 隔间** 合并邻对 。 在蜂窝中,这些控制器会添加或移除一个外部细胞,并保留其他细胞的大小. 两个相邻的蜂窝细胞共用一堵墙,比高的细胞要高.

对于精确的布局,切换到 **俯视** 并选择要分割的分隔区块。 选择 **零件数量** ,则 **宽度分割** 将宽度划分为更窄的隔间,或 **分为深度** 用来做更浅的。 可以再分一个结果. 对于两个小托盘旁边的铅笔湾,首先将宽度分成两块,然后将托盘侧面分成深度.

![一个全深的海湾和两个较小的隔间](../../images/compartment-splits.svg)

选择分隔符以拖动它, 或调整 **第一隔间** 在 **隔断位置** 。 只有选定的分隔符移动; 其他分隔符位置仍然固定。 相邻分隔符改变大小, 空间太小的分隔符被拒绝 。 请检查每一边新的内侧尺寸 。 **删除分区** 将分隔符合并起来, 也可以删除嵌入该分隔符内的分隔符 。 在删除分隔符前审查突出显示的选中符和确认符 。

<a id="wall-heights-and-cutouts"></a>
## 壁高与缺口

选择一个外墙或分隔器。 **一个高度** 设置了关卡。 **两个点** 允许您将高度设置在标在模型上的结尾 **A** 和 **B** 。 选择 **直接的** 、 **波浪形** 或 **之字形** 来塑造沿墙的边缘 。 波长控制了重复之间的距离 。 在一个阶梯模板中, 选择一个阶梯与链接的墙和分隔器一起调整它的关卡 。

使用 **连接相邻墙的高度** 使外墙跟随邻居。 对于分隔者来说, **适合相邻的墙壁** 复制过两端的高度。 在改变相邻墙后重复一次 。 **和别人一样** 将选定的墙返回到共同的高度 。

打开 **侧壁缺口** 以进行伸缩打开。 选择一个平滑的圆锥、 半圆圈或长方形的开口, 设置宽度和深度, 然后沿着墙壁移动 。 位置从 A 端到 B 端。 深度从顶端向下测量 。 请检查地板上方的余唇 。 选择 **无缺口** 来填充开口 。 Honeycomb 使用单元格高度 。 steped round 和 oval 不支持外墙的剪切 。

<a id="corners-edges-and-decoration"></a>
## 转角、边缘与装饰

打开 **形状 → 拐角和倒角**. 三个控件会影响打印的不同部分.

| 控件 | 向甚么处寻. | 改变的是什么 |
| --- | --- | --- |
| 外部角点 | 顶部视图, 外部大纲 | 环绕脚印角或砍在45°处,零度给出一个方角,可用在长方形的基座家族上. |
| 区间内的半径 | 顶部视图,在海湾内 | 绕过两面墙相交的垂直交叉点,紧湾限制了可用的半径. |
| 墙壁和分隔器的顶端 | 横穿墙壁 | **倒角**剪断扁平的贝子,**圆角矩形**曲折的唇,两侧的外墙和分隔器都得到尾部. **无**还原了方唇. |

![墙体横截面显示正方形、色调和圆形上角,壁厚度相同](../../images/top-edge-profiles.svg)

例如,在2毫米的墙壁上尝试0.5毫米的夹层. 每一边在顶部都损失0.5毫米,留下一个1毫米的平面条纹,显示的最大尺寸取决于壁厚度. 有了**圆角矩形**,值是半径,以毫米计.

- **收纳盒颜色** 更改预览和色能导出。选择一个监视、自定义的颜色或配置的丝状颜色。在导出时指定实际的丝状槽。
- **底部装饰边** 在基座上添加一个投影带。 选择平滑、 条纹或脚步裁剪并设定高度。 兼容的袖子可以停留在基座上。 Trim需要一个已整齐的单件体, 并且可以放在第一层上。 单独的面板坐在基座上方, 并带有选定的边缘偏移 。
- **收纳盒浮雕** 在外墙上直接添加了提升的图案。 滚动图案目录, 设定图案大小和减速高度, 并在每次计算完成时在拖曳时观看模型更新。 最终值使用完全精确度。 内部保持平滑。 预测会增加外墙的尺寸 。 选择 **光滑的** 来删除减速值 。
- **文字与图标** 将字母或符号放在选定的一侧。 请输入文字, 选择字体, 设定字母高度和垂直位置, 然后选择升起的字母或雕刻, 并设定其高度或深度。 恒星或心脏可以伴随文字。 在圆形和椭圆形组织者上, 文本和图标沿着曲线壁, 包括STL 和 3MF 导出。 字母间隔沿表面测量。 请选择 Front, Rear, 左侧或右侧, 将铭文居于该侧。 在有链接或不同壁高的圆形和椭圆形上, 将字母保留在壁下方和剪切度以下 。 蜂蜜组合字母尚未支持; 覆盖选定侧面和解弹也可以防止字母。 Flat- wall 字母仍然需要一个恒高的配置 。 如果文字被切入或超过可用面, 请降低位置或缩小字母大小 。

<a id="inserts-tiers-and-lids"></a>
## 内盒、层数与盖子

**可移动插入。** 选择一个隔间, 然后展开 **分格内衬** 右边 **空** 做一个开放的杯子。 **对于小事** 添加带有可调整行和列的网格。 **用于手柄** 为笔或工具创建套接字。 设定套接字的内径和套接字符合插入允许的数量 。 选择一个装配的,圆形的,圆形的,椭圆形的或六边形的轮廓和颜色. **移除插入件** 清除海湾。 空杯子仍然是可打印的部分.

该插件沿着其隔间至少0.5毫米清除。 它的墙壁和底部厚度为1.2毫米,其高度则调整到边缘下方约1毫米完成. 倾斜的组织器中的插件沿着斜坡伸出。 隔离 **内衬** 检查它们,然后导出 **整理器和配件** . 插入需要单件打印。

**堆叠的托盘。** 开始为关卡环形,然后打开 **形状 → 层数 → + 等级** . 可使用2至5级; **- 层** 删除一层。 梯级共用一个足迹,但可以有不同的隔间,高度,颜色和装饰.

1. 在模式上的 **收纳盒** 旁边的下拉中,选择 **第 1 层**, **第 2 层** 或另一级。该级是单独显示的,当前设置编辑器仍然打开 。
2. 以通常的形状、 隔间、 解析和 shell 控件编辑选中的级。 更改级不会将其设置复制到其他级 。
3. 在同一下拉处选择 **查看堆栈** 来检查所有级别和附件。 使用 **组装视图**, **收纳盒**, **内衬**, **外壳** 或 **盖子** 来显示您需要的部件。 返回到一个编号级别继续编辑它 。
4. 在**形状 → 层数** 下,调整**配合间隙** 并打印出一个小的适配样本,然后再投入全堆栈。位于轮廓上方的下层分隔器。堆积需要直立的墙壁和连续的支撑轮廓。

内置和 SVG 解析器在交配的领、舌和套接字保持平滑的同时装饰每层的外表。包装的贝壳和装饰面板可以覆盖各层。对于面板,请保留**边缘偏移** 至少3毫米,以便清除交配面圈。

用包裹的外壳,下壁内的舌头合上托盘地板下方的插座. 舱位宽度、深度和可用高度保持不变;每个套座为组装的堆外高度增加了2.2毫米。 火柴炮弹在窄0.8毫米支援波段相遇. 贝壳从上方滑动;在移除前,将各层分开。 每个外壳出口作为单独的阶梯编号部分.

**底部装饰边** 仅存在于第一层( 最低) : 选择平滑、 环或步骤 。 使用兼容的包壳, 修饰也支持外壳 。 单独的面板坐落在修饰上方, 选择的边缘被抵消 。 新的上层不会继承修饰 。 如果舌头不能适应壁厚度, 请减少 **配合间隙** ; 应用程序不会自动加厚墙 。 隔墙必须留下足够的材料, 以支撑上面的托盘 。

<a id="projects-and-backups"></a>
## 项目与备份

使用 **我的项目 → 保存副本** 在实验前命名一个设计或制作一个变体。 打开的工程会自动保存在这个浏览器中。 库允许您搜索、 打开、 重命名、 删除或下载一个工程 。 **保存项目** 在顶部的栏下下载一个可编辑的 JSON 备份 。 使用 **打开** 来加载该文件, 包括放在另一台计算机或本地安装中 。

强制编辑被立即保存。 当浏览器数据库保存时, 临时本地恢复副本保护更改; 如果写入中断, 重新恢复副本。 单独的最后一个成功快照可以恢复损坏的当前会话, 包括取消历史。 如果无法恢复有效副本, 自动保存停止, 而不是以启动模式取代存储的项目。 保留可下载的 JSON 备份: 浏览器数据清理或两种存储机制的失败无法自动恢复 。

导出检查属于当前工程修改、 选定部件和挂起位置。 更改这些修改会使上一个检查无效; 旧结果不能作为新模型下载。 失败的计算会保留编辑。 预览在两分钟后报告出错; 下一次几何编辑会开始新的计算 。

当同一个工程或抽屉被编辑到多个标签中时, 相互冲突的更改会被保存为单独的 **Copy from another tab** 。 另一个版本被保存, 编辑标签继续复制。 比较 **我的项目** 或抽屉选择器中的版本, 并重命名副本, 如果您想要保存的话。 重新打开一个组织者标签会恢复它自己保存的工程。 更改不会在标签中自动合并 。

在清除浏览器数据之前保留一个已下载的备份。 每个浏览器和站点地址都有自己的库。 Filament 插槽会单独存储在浏览器中的打印机。 在移动到另一个设备时再次设置它们。 关于可下载的本地应用程序, 请参见 [本地安装](../../../README.md#local-installation)。

## 打印设置与分段

在 **打印** 下,选择您的打印机和头部配置或选择 **自定义尺寸**。请检查构建宽度、深度和高度。预设会提供构建的音量。请在切片器中选择打印机、喷嘴、材料和切片配置。

对于超过床位的模型,请使用建议的切口,或在可用时选择两或三段。读取拟议的接合位置,并使用 **将部件分开** 查看各部分的相遇情况。分割将壁厚至少提升到5毫米,地板厚度至少提升到3毫米。重新检查内侧尺寸。在拆分前删除弹壳和插入。堆叠的托盘、倾斜的模型和圆形、椭圆形和蜂窝基部需要单件打印。**返回实体模型** 切换。如果想要恢复较早的尺寸,请再次检查厚度。

**连接样件**可下载接合部位的测试模型。使用与最终模型相同的缩放比例和打印设置，将样件分开放置，底面朝下打印。冷却后，标称直径 3.2×8 mm 的定位销插入直径 3.3 mm 的孔中；接缝两侧的孔深均为 4.5 mm。检查对齐后，用定位销和胶水组装打印好的分块。组织盒本体请使用**下载全部部件**。

<a id="download-and-slice"></a>
## 下载并在切片软件中准备

1. 内 **打印** ,如果想要多彩文件,则配置丝状槽。 与您的切片机匹配槽号和颜色 。 在一个 Snapmaker U1 ,插槽 1–4 对应 T0 – T3 . 最多增加16个插槽,设置每个颜色,并可选取其材料名称. 彩色是一种近似的视觉向导,而不是模拟一个印刷或混合的阴影. 在切片机中配置准确的颜色和混合 。 选择任何有丝卡并选择 **删除 N 槽中的丝线** 以删除它。 剩余槽号不改变:删除槽6 离开槽7作为槽7. **+ 槽 N 号** 再次增加最低可用数字;限值为16。 删除丝线不会改变模型颜色. 删除的插槽在导出时不再提供或自动匹配;在切片器中明确选择另一个插槽或指定它. 不同的颜色让应用程序将部分颜色自动匹配到槽中. 如果两个插槽共享一个颜色,请在下载对话框中选择每个部分的预定插槽.
2. 单击 **↓ 下载** . 选择 **整理器和配件** , **仅外壳** 或 时 间 **整套** ,根据您需要的部件。 对于一个分门别类的模型,导出工具包.
3. 在下面选择一个格式。 对于 3MF, 给每个部分指定一个丝状槽, 或者把它留在切片器中指定。 Orca 可以使用第一个丝状槽来进行未指定的部件 。
4. 等待几何和大小检查。 读取每个部分的尺寸和任何在床上旋转90°的指示。 检查在床边保留了2毫米。 下载时要使用对话框底部的格式按钮 。
5. 在切片软件中打开导出文件，使用**毫米单位和 100% 缩放比例**。排列所有零件，检查悬垂和细小结构，并预览首层及隔板。多色打印前，请确认每个零件的耗材分配。

| 格式 | 选择它 | 下载怎么办? |
| --- | --- | --- |
| STL 编 | 单色打印的几何 | 在切片器中打开 STL。 如果导出包含多个 STL , 请先提取 ZIP 。 |
| 3MF | 具有不同部件、颜色和丝线任务的工具包 | 在切片机中打开并验证部件和插槽。 ReplixGrid 将打印机和材料配置文件留给切片机 。 |
| OBJ + MTL | 接受 OBJ 工具的彩色模型 | 将几何学和材料文件保存在一起,模型使用Z上方的毫米. |
| JSON项目 | 继续编辑隔间、尺寸或附件 | 使用**保存项目**并在ReplixGrid中与**打开**重开. |


为了配合你的切片机的数码颜色, 粘贴它的六位数 **HEX 代码** ,例如, `#E63522` 在采色器旁边 领先者 `#` 是可选的。 有效的代码立即更新预览;不应用不完整或无效的文本,并在退出字段时返回保存的颜色. 一个匹配 HEX 代码不模拟丝状外观、照明或物理颜色混合物。

<a id="shared-styles"></a>
## 共享样式

1. 打开一个带有您想要重复使用的颜色和图案的工程 。
2. 在 **形状 → 通用样式** 下,输入名称并点击 **保存当前样式**.

<a id="mounting-plates"></a>
### 安装底板

在 **Drawer → Drawer base** 中选择 **Mounting plate**。抽屉的长宽和侧壁间隙决定覆盖面积。分别输入 **3D 打印机热床**的可用宽度和深度；这些尺寸决定单块板的最大尺寸和分块数量。计算包含连接结构的突出部分，并在热床每侧预留 2 mm 打印余量。尺寸无需是 20 mm 定位网格的整数倍；边缘分块会适配剩余空间。

**Download sections (ZIP)** 每个打印任务创建一个编号为 3MF, 一个 SVG 组装图和坐标列表。 该地图使用原始抽屉方向, 独立于视图旋转。 R 表示从上到下行, C 列从左到右。 下邻尾从上到右。 首先打印 **Download joint sample** , 包含两个小的相邻部分; 打印完整集前先用打印机检查组装。 关节使用 0.05 mm 的接合器和 0.03 mm 的配置配置宽度。 微弱的接合器和轻微的播放可以保留在空段之间 。

启用板块模式后, 托盘下载包括该托盘位置和旋转的下侧套座。 内部隔间尺寸被保留。 托盘高2.1 毫米; 包括2 毫米板块, 抽屉适配检查会增加4.1 毫米。 在移动或旋转托盘后, 重新下载: 其套座必须匹配套座位置 。 更改抽屉清除也会改变连接源 。

袜子射线清除为0.12毫米. 打印一个横跨两节的小组织器,以检查是否适合您的材料和图层设置 。 套接字会横向保留组织者; 向上提升以删除它 。 导出只使用几何:在切片器中选择您的打印机和材料配置,并在打印前检查套接字顶部 。

挂载当前支持不倾斜的未分割组织者, 至少有三个完全支持的套接字。 小托盘可能需要移动或扩大 。 上层和贝壳保留现有的几何。 关闭盘片模式以导出原始未挂载的模型 。 保存的源项目保持不变 。

<a id="custom-svg-relief"></a>
## 自定义 SVG 浮雕

在 **形状 → 收纳盒浮雕 → My SVGs**, 选择 **Upload SVG** 或将一个文件降入上传区域 。 选择一个保存的缩略图来重用它 。 在 **形状 → 盖子 → My SVGs** 和 **外壳 → 图案 → My SVGs** 下 , 同一库可供使用 。 每个目标都保持自己的模式和位置设置 。

选择 **Single motif** 或 **Repeat**, 选择外墙, 并按毫米、 旋转、 水平/ 垂直抵消和重复差距调整外墙宽度 。 宽度和高度保持原比例 。 放置在每一个选定的侧面上; 侧面对应于四个外侧区域 。 垂直偏移正向上。 模式遵循外侧轮廓 。 重复只放在完全的侧面下方、 四周和两侧之间 。 在这些边界上剪剪切 。 使用现有的 **救援深度/强度** 控制 。 保留原有的壁和内侧面。 外部尺寸增加 。 等待更新预览完成后, 然后检查和下载该部分 。

支持的 SVG 包含填充路径、多边形、矩形、圆形或椭圆, 包括孔和组变换。 在从向量编辑器导出之前, 将文本和中键转换为填充路径 。 照片、 外部引用、 过滤器、 口罩、 剪切路径、 梯度、 CSS 样式块和可重复使用元素的引用( `use`) 不支持 。 忽略包含支持形状的空定义或未使用的定义 。 颜色会使用组织器的颜色成为单一的升起形状 。 限制是 200 KB、 512 XML 元素、 128 填充形状和 6 000 个样复发点; 使用信件拒绝过于复杂的模式或过多的重复 。 用于打印的缩略图。

SVG 在浏览器中本地处理。 库会保留在这个设备上。 每个工程都会嵌入一个其已使用轮廓的独立拷贝, 所以下载的项目可以在另一个设备上重新打开, 而不用源 SVG 或库。 删除一个库条目会保留已有的项目不变 。 **通用样式** 还会将自定义的正文、 盖子和 shell 模式带给另一个组织者 。 缺少的盖子或贝壳会被跳过, 就像内置样式一样。 保留一个下载的项目作为备份 。

<a id="choose-an-svg-for-its-intended-use"></a>
### 根据用途选择 SVG

SVG是一种绘图格式,而不是可打印几何的保证. **导入成功仅意味着所支持的填充大纲被读取 。** 选择的表面,大小和应用模式仍然需要通过几何检查.

| 预定用途 | 填满的区域变成什么 | 准备什么 |
| --- | --- | --- |
| 组织者救济 | 固壁上附着的升起材料 | 分开的齿轮和内孔可以起作用,因为墙壁支撑着它们. |
| 升起的盖状图案 | 坚固支持的材料 | 内孔是允许的;将整幅图画保存在可用框架内,并清除手柄落地. |
| 通过开口连接 | 从盖子上移走的材料 | 每个剩余部分必须连接到周围的盖子,封闭的内饰需要刻度桥. |
| 包装的外壳或装饰面板 | 打开封面 | 使用与速率兼容的绘图。 剩余框架和图案必须形成连接的材料 。 |

要准备文件 :

1. 保留预定的填充路径或基本形状。在向量编辑器中将文本和**切换到轮廓**。带有`fill="none"`的可见行是中风,而不是填充区域。
2. 删除背景矩形, 除非您想让整个区域成为解脱或开口。 SVG 颜色不分离材料, 白色形状不会自动抹去下面较暗的形状 。
3. 请检查向量编辑器中的复合路径。 说“ 孔” 的注释不会产生一个路径: 路径的风化和`fill-rule` 确定内区域是否被填充 。
4. 通过开口,将封闭的内层细节与周围材料连接到桥梁上。 增加重复的齿轮之间的间隔**没有** 在齿轮内部附加一个松散的细节。 或者,在盖子上使用提高的宽度。
5. 偏好重复模式的单个摩托。 如果 SVG 已经包含一个摩托的网格, 其宽度设定大小为 **整个网格**, 而不是每个网格。 小的特性可能变得过细, 无法打印 。
6. 等待一个成功的构建和导出检查, 然后检查切片器预览 。 如果构建失败, 场景可能保留最后一个成功的模型; 该模型并不代表当前失败的设置 。

例如,一个坚固的叶片可以起到解脱作用,也可以起到叶片形状的开口作用。一个完全封闭的叶片可以起到解脱作用,但是切除周围的叶片可以使静脉松散。一个填充的六角形网格可以起到穿孔作用,如果剩下的网保持连接和足够厚;必须先准备一个用中风绘制的多色插图。

<a id="svg-lids-and-perforated-shells"></a>
### SVG 盖子与镂空外壳

添加盖子后，选择 **My SVGs**。**浮雕（装饰）**模式在实心底板上生成图案，形成一体式盖子；可设置浮雕高度（0.2–1 mm）和底色。**镂空模板（切割）**模式将 SVG 的填充区域贯穿切除。两种模式均保留 2 mm 边框和配合边缘。独立把手下方保留实心支撑区；如果单个图案与把手冲突，请移动图案。外盖和嵌入式盖子使用相同的控制项。SVG 中的颜色不会导入为独立耗材。

对于外壳,请选择 **My SVGs** ,然后是图书画。 填充区域通过开口而变为填充区域. 在一个包裹袖子的选定侧面使用一个摩提夫或重复。 打开 **装饰板** ,每个选定的面板上独立重复绘制图;保留现有的框架和挂载位置。 初始的motif大小会考虑贝壳高度. 根据需要调整框架宽度、移动大小、旋转、位置和间隔。 组织者内部隔间及外壳清空情况不变.

在盖子和贝壳上, 仅将完整的齿轮放置在可用框内, 包括单个齿轮。 如果无任何齿轮适合, 缩小大小或抵消。 闭合的内饰细节( 例如环形剪切的中心) 可以变成松散的岛屿 。 在您的矢量编辑器中添加桥, 或者在盖子上使用提升的装饰 。 应用程序会断开几何, 而不是静静地丢弃棋子 。 避免非常狭窄的网, 并检查您的材料和喷嘴的小型测试指纹 。

模式包含在单个部分的导出, 完整套件和全画幅打印任务中。 切换到 **Built-in** 只会从目标中删除自定义模式 。 删除一个库缩略图不会从项目中删除嵌入模式 。

<a id="numeric-sliders-and-valid-ranges"></a>
### 数值滑块与有效范围

数字设置显示**最小数**和**马克斯**在一个薄绿色轨道上方,对当前值有一个白色标记。红色端盖标记所允许间隔的外部;它们不是打印强度的评级。拖动标记,在聚焦时使用箭头键,或输入精确数字并按下 Enter。数字字段和滑动器使用相同的限制。有些限制会随着模型的变化而改变;滑动器范围内的值仍然可以与另一个设置相冲突,因此在导出前遵循任何几何警告。

<a id="whole-drawer-export"></a>
## 导出整个抽屉

选择 **DRAWER → Print entire drawer** 以准备所有托盘、其附件和任何启用的挂载板块。 挂载托盘会接收保存位置的套座; 普通的自由置放托盘会保留其现有的基座。 拆分打印项目包括部件和针头。 重叠、 抽屉检查不足、 不支持挂载或无效的几何设置屏蔽下载并识别受影响的托盘 。

设置 **Printer bed length**( 横向) , **Printer bed width**( 垂直) , 打印高度和间距 。 初始维度来自挂盘设置或第一个托盘的打印区域; 随后的导出设置会用这个抽屉保存 。 挂盘部分会被重新生成到选中的床位。 这不会移动托盘或修改保存的源工程 。

版式使用实际导出的边框, 床边的2毫米边框和所选择的间隔。 部件可以旋转 90 度。 多色盖组件保持在一起。 显示的床位计数是用于此安排, 而不是一个保证的最小值 。 不包括支持、 凸轮、 清洗塔、 打印机禁区和不同的物质任务; 保留适当的空间, 检查您的切片器中的结果 。 没有嵌入打印机配置文件或丝槽分配 。

ZIP 中包含每个打印平台对应的 **bed-NN.3mf**、配套的 **bed-NN.svg** 示意图、**assembly.svg**、**print-plan.json**、**drawer.replixdrawer.json**，以及 **README.txt** 中的编号零件清单。将每个 3MF 文件作为独立打印任务打开，保留各对象的相对位置，使用毫米单位和 100% 缩放，并分配耗材。SVG 示意图显示包围矩形；3MF 包含完整可打印几何模型。抽屉组装坐标始终以长度为横向、宽度为纵向。

对布局或导出设置的更改使先前的计算无效。 关闭窗口会取消准备。 超大小的单个部件会被报告, 而不是默默缩放或自动拆分。 可能需要以较小的组数导出非常大的套数 。

<a id="pattern-studio"></a>
### 图案工作室

选择 **提高救济(勋章)** 或 时 间 **通过stencil(剪切)** 在右手设置的顶端。 贝壳只支持stencil模式. 设置只显示解脱高度,而间隔只显示重复放置。 **材料厚度** 可编辑: 1.2 - 6毫米 SVG 盖子和1–4毫米用于壳体. 它会一起更改预览和导出 。 现有的遮盖默认值仍为解除值3.2毫米,齿轮为2毫米;在切换模式时保留选定的厚度. 降水高度包括在盖子厚度中。 一个内置 SVG 盖面要求内部深度至少为板厚+2毫米. **附加** 包含盖子颜色或 shell 墙壁选择。 打开 **哪个 SVG 文件有效 ?** 进口限额和准备咨询。

打开 **形状 → 盖子 → My SVGs** 或 **外壳 → 图案 → My SVGs** 编辑底部抽屉中的附属图案。 **盖子** 和 **外壳** 标签在共享 SVG 库时保持独立设置。 切换标签会自动隔离预览中的该部分。 如果尚未添加, 组装会保留到创建该部分。 您仍然可以手动在模型上方选择大会。 使用宽度、 旋转、 间隔和 X/ Y 控制来定位 motifs; 中键重排位置和旋转。 盖会支持提升宽度或通过打开。 Shell 打开框架和挂起区域。 关闭 X 或 Escape, 在工作室中集中; 编辑仍然保存。 Arrow key 切换聚焦的表面标签 。
